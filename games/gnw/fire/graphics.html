1981 · Nintendo

Fire: Graphics

Every shape is fixed on the glass. A person flies by lighting the next shape along the path, and the firemen, the smoke and the angels move the same way.

01 · Everything that moves

Every position of every moving object

Each figure lights its object's shapes in the order the game does, one change a move.

At the start of a game a step takes about 0.2 s and each part of the path moves once every three steps, so a person moves a place about every 0.6 s; these figures move at that pace. The firemen move as fast as the presses come, one place a press.

Each place on the path is a whole figure, tumbling in a different pose at each place of its arc, and the last place of each arc, above a net, is drawn as he lands. The smoke over the building rolls outward in a wave of four puffs.

02 · The bits behind the shapes

Where each object lives in memory

Each shape is one bit of one cell. Hover over or tap a row to light its shapes.

A cell's four bits drive the four shapes of one LCD latch; rows 0 and 1 of memory are the two halves of the screen ($0640). The arcs cross from cell to cell, so the code that moves them names each bit it passes.

03 · Fixed shapes

Two places of the path are spare digit segments

The chip's digit table gives each of the three digits one spare segment, and the game uses all three ($0648): the first is the clock's colon, and the second and third are places in the third arc, at the top of its curve.

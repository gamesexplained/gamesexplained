1981 · Nintendo

Popeye: Play

The whole unit, clock and alarm included, written again in JavaScript routine by routine, and run in lockstep with the chip's own program in the tests.

01 · Play

Catch what Olive throws

The unit starts as a fresh battery leaves it, every segment lit. Press Time for the clock, or Game A or Game B to play: the game starts when you let go.

Keys: ← → move Popeye; A Game A, B Game B, T Time, L Alarm. With Computer plays on, the page's own player moves Popeye under the lowest item and never steps him under Bluto's lowered weapon; press left or right to take over.

Each press of left or right moves Popeye one place; hold Time in the clock to see the alarm's time, hold a game's button to see its best score. After a game is over the buttons choose the next one.

02 · The port

The chip's program, routine by routine

Nothing on this page runs the game's own code. Each routine of the listing is a JavaScript function of its own, on the game's own 65 cells of memory, with the chip's registers kept where one routine hands them to the next. The port also keeps the chip's clock. The SM5A spends one cycle on each byte it runs, so each straight run of the program costs its length, and the port's cycle count stays the chip's. The game takes its chances from the chip's divider, a counter of the crystal, and keeps time on its one-second flag, so with the same cycle count it throws the same items at the same moments and the clock keeps the same time.

The test beside this page, test_play.js, runs the port in lockstep with the game's code on the kit's model of the chip, which is held to MAME instruction for instruction. At every turn of the main loop, every count of the delay before a step, and every pass while a game key is held, the two must agree on all 65 cells and on the cycles since power on. The test drives both with this page's computer player through ten minutes of Game A and B and the clock, and through the rare states by setting the game's own cells: the bonus at 200, a game ended by Bluto, the "infinite lives" pad, the alarm going off, and the test pad's three uses.

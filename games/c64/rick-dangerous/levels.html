01 · The levels

Four levels, top to bottom

Each picture below is a level's map as the game stores it: rows of eight block numbers ($9200-$A5BF), each block four tiles by four ($8200), each tile a character from the level's tile set with its colour from the tile colour table. The game shows six map rows at a time and scrolls by two when Rick nears the top or the bottom of the screen; rooms to the left and right are further stretches of the same map, reached through the exits. Objects, enemies and traps are not part of the map and are not drawn.

Drawn by this page from listing.json: levels 1 and 2 with the tile set at $D000 and the colours at $8000, levels 3 and 4 with the second set at $7000 and $8100, which $1911 swaps in; the two shared multicolours of each level from $1988 and $198C. Each level runs from its first room's map address to the next level's. test_maps.js checks the decoding of every map row against the game's own $2D59 in the kit's simulator.

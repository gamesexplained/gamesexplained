## Native and extracted pictures

PNG files were captured locally from the supplied private images or drawn from extracted glyph bytes. `black-title.png` is a completed native title; `black-playing.png` is active room-one play with 250 points. Gray and Yellow attract screenshots establish native boot, not every gameplay feature. `crt-demo.png` shows a cartridge attract board; `crt-play.png` shows cartridge room-one play. `editor-menu.png` and `editor-initialize-warning.png` show the original disk editor reached via its documented command latch; initialization completion is unproved. `glyphs.png` is the extracted atlas.

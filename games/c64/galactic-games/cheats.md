# Galactic Games — cheats

Pokes that change the game within its own parameters. Each one names the
variable it changes and whether it has been tested live. Untested pokes are
labelled as candidates.

No cheats are known for this game, and none was tested in this run. The
Marathon's energy (marathon `$1F1F`, 16 bits, `$03FF` full) and its drain
(`$1F23`, every 20 frames) are where an infinite-energy poke would start.

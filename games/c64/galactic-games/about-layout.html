About this page

The copy studied

The pages describe Activision's disk, both sides, as two G64 images. The directory of each side is a picture drawn in graphic characters, and every entry on side 1 points at the boot program. The boot loads a resident part that stays in memory to the end: the loader, the title screens, the records and the Galactic Championship ($B800). The resident loads the menu, and the menu loads the five events, 100m Slither and Space Hockey from side 1 and the other three from side 2. Each of those seven loads has its own listing on the Source tab, built from memory saved while it was running. The records are kept in a file on side 1, and the copy studied holds the records it was sold with. Nothing on either side suggests a crack or a trainer.

No game image is hosted here.

Original game credits

The game's credits screen names Tigress Designs for the design, SYSTEM for the development, Martin Chatfield and SYSTEM for the graphics, and Software Studios as the producer, in association with Tigress. Activision published it.45 No programmer or musician is named on screen, in the files, or in any of the sources below.

Memory footprint

Every byte of the C64's 64 KB, one pixel each, 512 to a row. Lit pixels are code, graphics, sound, text, tables and variables; dim areas are screen and working memory.

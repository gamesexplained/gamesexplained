WIZARD CONSTRUCTION (BLDR): interpreted-source companion

This is an analysis of the separately loaded BLDR overlay, not GAME addresses.
No executable program is included. A/B mean interpreter accumulators; Vn are reused scalar slots.
Runtime $0826-$27F1 is byte-identical to the annotated GAME runtime in the main Source tab.
$0801-$0818: BASIC SYS entry stub; $0819-$0825: JMP plus five image-header pointers.
$27F2-$27FF: shared runtime end padding; $2800-$291B: scalar template records.
$291C-$2DA1: packed DATA described below; $2DA2-$330B: cleared array storage.
$330C-$331F: two five-byte array dimension initializers, type-$64 terminator and retained padding.
$3320-$530C: complete decoded script below (3830 instructions).

PACKED DATA: each header carries textual length in bits 0-5. Bit 6 appends an integer byte; bit 7 appends an integer word. Text remains available to string READ.

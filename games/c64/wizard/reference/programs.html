Program source browser

Construction and individual rooms load different code into the same memory addresses. Choose the program first, then search its instructions or jump to a section.

Click an instruction address to get a link to that exact program and line. Blue operands link to decoded instructions; other addresses can refer to data or a different image. The resident Source tab contains the shared engine and interpreter.

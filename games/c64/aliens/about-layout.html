About this page

The copy studied

The pages describe the American Activision release on disk, in a cracked copy. A Remember cracktro and trainer, a 22 KB BASIC program at $0801, hold the game's engine and load the stages from ten packed files, A0 to A9. The engine's listing is built from memory saved at the trainer's menu, and each stage's from memory saved while it was played. The trainer's patches are the cracker's, not Activision's, and the Source tab marks them so. Whether the engine of an uncracked disk differs was not checked.

Memory footprint

Every byte of the C64's 64 KB, one pixel each, 512 to a row. Lit pixels are code, graphics, sound, text, tables and variables; dim areas are screen and working memory.

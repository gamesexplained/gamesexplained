Mark Cooksey's driver and tunes, played by the game's own code, and the game's eighteen sound effects.

01 · The music

Music: Mark Cooksey's title tune

The title program carries a music driver and three tunes. The ending loads the same file again and plays the title tune for ever.

The game's own driver, running in your browser. This player runs the bytes of the file MUSI ($E000-$F5D5) on the site's 6502: $E000 starts a tune and $E003 plays one frame of it, as the title's raster interrupt calls it. A test beside this page checks every register the page's player writes against the same code run on the title's memory. Tune 0 plays on the title; tune 2, started when you choose a man, holds a note for a few frames and then stops the music; the game never calls tune 1.

Each voice reads a stream of notes: a note number, then a byte with its length and instrument. Bytes from $60 are commands: play a pattern (with repeats and a transposition), loop, slide, pick a filter sweep. The game itself has no music: its sound effects come from a smaller engine at $F88C, eighteen effects of a few bytes each.

About this page

The copy studied

The pages describe a PAL disk release in a G64 image whose title program is the file LOADER. The game is three programs: the title and select screen, the game, and the ending. Each has its own listing on the Source tab, built from memory saved while it ran, the game's on stage 1A as Riggs. No game image is hosted here.

Memory footprint

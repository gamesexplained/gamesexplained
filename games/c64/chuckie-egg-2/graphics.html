Graphics

All 128 sprite shapes, every picture Harry can pick up, the four toys, and the character set the rooms are built from.

01 · Sprites

128 shapes at $2000

Harry, the creatures, the train, the dog, the van and the lifts are sprites. Their shapes fill $2000 to $3FFF, shape numbers $80 to $FF. Big creatures are built from several sprites side by side, and some are stretched to double width or height.

Every shape in one colour, from the bytes in the listing, grouped by the labels in the Source code tab. The game sets each sprite's colour as it draws it; none of them uses multicolour mode ($495B).

02 · Pick-ups

Pictures drawn in characters

The things Harry picks up are not sprites. Each room's pick-ups have their pictures copied into the character set from $0AE8 as the room is drawn. The pictures are at $8A00 to $8EFF, each starting with its height and width in cells. The table at $576C points to 37 of them.

Pictures $08 to $24 of the table, with the names the game gives them where it gives one. The rest are numbered only.

The first eight pictures, the toy parts, and picture $0E, the toy, change with each egg. At the start of an egg pickups_init ($7B75) copies one of four sets from toy_sets into the table.

The four sets at $7BAF, $7BC1, $7BD3 and $7BE5: eight toy parts and the toy each. Egg 5 uses the first set again.

03 · Characters

The character set at $0800

The rooms are drawn in these 256 characters: the scenery, the cells the pick-ups are copied into, and two fonts. These are the bytes the file loads, before the game has drawn any room, so the cells the pick-ups are copied into still hold what the file brought with it.

Characters $00 to $FF, 32 to a row, from the listing.

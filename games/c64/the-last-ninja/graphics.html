Two sprites make one ninja

Armakuni’s head and shoulders occupy one hardware sprite. His feet occupy another directly below. The two sprites move together while the game replaces their bitmap data to change his pose.

VIC spriteBitmap in RAMX, Y

These are the distinct poses captured while holding right in the first Wastelands room. Each hardware sprite displays 24 by 21 pixels here. The pointers occupy two adjacent bytes at $C3F9 and $C3FA.

Sprite bitmaps

The engine has a set of packed sprite bitmaps, and each chapter supplies its own directly stored frames. The viewer shows the stored bits. The game sets the colour when it assembles a pose.

Source addresses

The packed format uses a single byte for a run of zeros. An escape byte lets a literal use the same value as a command. See the decoder at $7E36.

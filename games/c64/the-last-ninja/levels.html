Room pictures

Browse the background art for each chapter. The pictures come from the game’s own drawing routine. Sprites and objects that the game adds during play are a separate layer.

Each picture record picks a shape script. A flag selects which of two pointer pages supplies the script’s address, so two picture slots can point to the same scene. The low four bits of the last byte set the background. See the renderer at $5DFE.

The game turns a point along the boundary into a number that runs clockwise around the playfield. It uses four limits in the room’s exit record to decide where that point leads. The destinations in the table reflect the edge data. The room’s paths and obstacles determine which exits Armakuni can reach. See the boundary check at $7478.

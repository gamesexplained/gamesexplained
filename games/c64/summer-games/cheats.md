# Summer Games — cheats

Pokes that change the game within its own parameters. Each one names the
variable it changes and whether it has been tested live. Untested pokes are
labelled as candidates.

No cheats are known for this game, and none was tested in this run. The
world records are a file, WR, that the game loads at boot and writes back
after a new record (resident `save_records` `$1563`); editing the file's
160 bytes, laid out as the factory set in DEFAULT, is where a record
editor would start.

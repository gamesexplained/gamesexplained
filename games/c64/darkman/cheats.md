# Darkman — cheats

Pokes that change the game within its own parameters. Each one names the
variable it changes and whether it has been tested live. Untested pokes are
labelled as candidates.

| Effect | Poke | Status |
|---|---|---|
| Skip a level with the space bar, and no game over | type BABY AXE MAN on the title pages, or poke `$0A11` to 1 (level 1; the flag is at `$0A11` in every level) | typed live on the title pages: the flag went from 0 to 1; space with the flag set ended play in level 1 |

01 · The boy and the girl

One set of moves, drawn twice

The boy and the girl share one set of moves: four frames walking each way, two in the air, and two standing. The small arrows on the frame sheet download each character’s walking animation.

The boy's frames at $3600 (pointers $D8-$E7), the girl's at $3A00 ($E8-$F7), in the order the game uses them: walking left, walking right, jumping, and standing.

GIFs use the gallery’s colours, black background, and three-times pixel scale. Each frame lasts 0.16 seconds; this is the gallery’s preview pace.

A sprite pointer is the number used to select one small character picture. The girl’s frames sit exactly 16 pointers after the boy’s, so one set of routines can draw either. player_swap ($576B) adds or takes away that 16 in the three places the frame numbers are kept.

02 · The enemies

Seventeen animations for fifty enemies

Ten screens with five enemies each make fifty enemies, but the game draws them with only seventeen animations, shared between the screens. Each one below plays through its frames, with the screens that use it. The small arrow on an animated image saves it as a GIF, looping at the same pace as this gallery.

Each animation in the colours of the first screen that uses it ($D029-$D02D), with the shared multicolours of $D025 and $D026, at three times the C64's pixels.

Each screen's settings name the first and last frame of each of its five enemies (setup_screen, $5E19). Most animations have four frames, but four of the cinema's five enemies have one frame each and never change shape, and one of the ghetto's has eight. Most of the shapes are stored at $2000-$29FF, and seven of the ten screens also use a second store at $0B00-$0FFE.

The final entry is a bug rather than an intended animation. One enemy in the forest on the way home is told to run from frame $88 to frame $F2, so it plays 107 frames, most of them memory that was never meant to be a sprite. The Discoveries tab shows why.

03 · The loading picture

A picture behind a rainbow

The 1984 cassette loads its picture with the screen switched off, then puts it up whole, about 70 seconds into the tape: the girl, the boy turned monster in a blue jacket, a tombstone marked RIP, bats across a full moon, and CHILLER in dripping letters. It stays up, in silence, for nearly three minutes while the game loads.

The cassette's own bytes, recorded in VICE with the picture up and drawn as the video chip draws them, with the border as the loader painted it in that one frame.

The stripes are the loader's. It moves the border on to the next of the C64's sixteen colours each time it reads a bit from the tape, so every stripe is one pulse of the signal: a thin stripe a short pulse, a thick one a long pulse. The colours run in the chip's own order, black, white, red, cyan and on to light grey, then round again.

The memory as the game uses it

Hover for the address; click to open it in the source.

One dot per byte, 128 to a column, from $0000 at the left to $FFFF at the right, laid out and coloured as the Source tab's map. A byte the game wrote in the last frames flashes white and fades; the routines the game ran in the last frame are striped (those the lab below lists). The port reads its memory directly, so only writes can be seen, not reads.

The sound chip's three voices

Each bar is a voice's loudness, worked out from the attack, decay, sustain, and release the game sets; the mark is its sustain level. The note is the voice's frequency register on a PAL machine. The tune plays on voices 1 and 2; the game's sound effects use voice 3.

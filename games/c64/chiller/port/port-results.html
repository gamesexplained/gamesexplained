Nothing on this page emulates a 6502. The game's 188 routines are written out in JavaScript, one function each, named by the listing's labels, and run on the game's own 64 KB of memory.

The page loads that memory from the listing, the same bytes the Source code tab shows. From then on the port reads and writes the game's variables where the game keeps them, draws the levels from the game's own maps, plays the game's own tunes and puts its sprites where the game puts them. The picture is drawn from that memory as the video chip would draw it.

Where the original depends on its interrupt

The music and the keyboard scan run 60 times a second from a timer interrupt, which on the C64 can fall between any two of the game's instructions. The port runs it between its own steps.

  • The random numbers. The game makes a random number from its own code bytes and the low byte of the KERNAL's clock, which the interrupt counts up. When a tick falls between two draws, the second draw sees the new clock; on the page the tick comes between the port's steps, so the draws can differ.
  • The collisions. The video chip sets its collision registers while it draws, and the port reads them a little before the game gets there.
  • The wait for line 16. Before it flickers the border while your energy drains, and before it swaps the boy and the girl, the game waits for the raster to reach line 16: it reads the line, compares it with 16 and then checks the ninth bit. Now and then the interrupt falls between the read and the check, and takes 18 lines. The game then leaves the wait on line 34 or 35 instead of 16. The port always leaves on line 16.

Speed

The game runs about fifteen passes of its main loop a frame, so a port that ran as fast as the browser can would be a different game. The page keeps a PAL machine's clock, 312 lines of 63 cycles, and each routine the port calls moves it on by that routine's own cycles. The interrupt's own time is added where it falls. Over all ten levels, standing still and walking either way, the page runs within 4 % of the C64's speed.

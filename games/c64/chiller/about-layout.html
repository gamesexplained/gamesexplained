About this page

The copy studied

The copy is a single program file of 42,860 bytes (MD5 71f92e5380d4564acb7970f9caee2502). Its loader moves most of the file to where the game runs, so everything on these pages is read from memory as play begins, not from the file. The loader leaves the mark (ANTISOFT) behind it, which is not part of the game itself.

It is the first release, the one with the Thriller tune. Its music player and all 4,238 bytes of its tune data ($61F2-$727F) match the steward's transcription of the first release byte for byte, and about 1,650 of them differ from the re-release.11

Memory footprint

Every byte of the C64's 64 KB, one pixel each, 512 to a row. Lit pixels are code, graphics, level data, sound, text, tables and variables; dim areas are screen and working memory.

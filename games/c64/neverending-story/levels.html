01 · The map

Every room, joined by its exits

Each part's rooms, placed by the page from the ten exit tables ($16B4). The rooms the eight compass exits join make a floor, which the page lays out on a grid of its own, a room one square from the last in the direction the exit leads; up and down join the floors. Where two rooms would share a square, the second moves to the nearest free one, so a line can run longer than one step. Pick a room to see it below.

A line is an exit both ways; an arrow, an exit one way only; a dashed line, up or down. The ring marks the room a part starts in, the double ring the room it ends in. A script can also put Atreyu in another room (action $18); the room below lists those moves in its script.

02 · The room

Each room as the game draws it

The room's script, every turn

    The picture and the description are drawn by the How it works page's ports of the game's blitter and printer, which test_pictures.js and test_text.js hold to the game's routines. The exits are read as ACTION_MOVE_DIRECTION ($0E3F) reads them, which test_rooms.js checks for every room and direction, and the scripts as RUN_SCRIPT ($1605) reads them, checked by test_scripts.js. How a script is built is on the How it works page (The scripts).

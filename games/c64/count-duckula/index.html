1989 · Alternative Software · Commodore 64

Count Duckula

A pyramid built from tiles, a clock that enemies can hurry, and an inventory that drops its oldest object.

01 · Count Duckula

A saxophone before dawn

Duckula explores an Egyptian pyramid in search of a magical saxophone. Useful objects sit among locked doors and wandering enemies. His castle leaves at dawn, so the clock ends the search.

Items fill three carrying slots. Picking up another object drops the oldest one beside Duckula. Keys have a separate counter.

02 · Count Duckula

Music: the television theme

The game’s own player at $0E00 runs on a model of the C64’s processor and writes to a model of its SID sound chip. The page calls the player once per PAL screen refresh. The filter switch models one 6581 chip. The game requests the theme with $87 at $24B7.

The player has separate sequences for its three voices. Sequence bytes choose patterns, and patterns choose notes and instruments. Each instrument controls the note’s attack, waveform, and changes in pitch or pulse width. The page uses the same starting request as the game.

03 · Count Duckula

The opening screen from memory

This opening state matches all 104,448 pixels in the emulator’s picture. The page draws the bitmap, colour planes, and three Duckula sprite components from the captured display data. This state can be drawn without changing the video settings partway down the screen. Room geometry is decoded separately in the room viewer.

04 · Count Duckula

A jump written as a list

A long jump follows a fixed list of vertical changes at $39A4. The game subtracts each positive or negative value from Duckula’s height, so positive values lift him and negative values bring him down. Directional jumps also move sideways. A wall or doorway can end the jump before the list ends. Falling uses a separate list that reaches a four-pixel downward step.

This graph shows the stored displacement list, without simulating collision or a route through a room. The movement reader is $362A, the jump handler $388D, and falling $39C7.

05 · Count Duckula

The oldest object goes back on the floor

The carrying slots behave as a queue. A pickup shifts the middle and newest objects toward the oldest slot, then appends the new object. If the oldest slot was occupied, its object returns to the world at Duckula’s position. Pickup protection lasts 150 updates, giving him time to move away.

Number keys 1, 2, and 3 use the corresponding slot. The sandbag and death mask fit particular doorways. A hammer opens the canopic jar, revealing the large key for the saxophone. These uses need a particular room and position. The room viewer marks the two special door rooms and the completion area.

Queue and drop handler: $4145. Item-use tests: $42D2. The numbered display illustrates slot order; its numbers are examples.

06 · Count Duckula

More actors than hardware sprites

Duckula uses three hardware sprites, the small pictures the video chip can move over the background. That leaves five of the C64’s eight sprites for everything else. A display routine reuses those five as the screen is drawn downward, taking actors from a list sorted by height.

The actor list separates position, picture, and colour into parallel arrays. The screen routine reads one actor’s entry from each array and programs the next free sprite. The graphics viewer shows all 104 stored shapes.

Schedule builder: $2908. Sprite reuse: $29BE. The background is a multicolour bitmap assembled from 16-by-16-pixel tiles by $2E53.

07 · Count Duckula

The clock has several entrances

The ordinary countdown waits seventy gameplay updates between displayed seconds. Contact with an enemy enters the decrement routine directly, so the normal divider does not protect the clock during contact. The brief colour flash is a separate effect.

The ankh adds two to the hours digit when collected, capped at 9:59. Igor’s visiting group has another one-use bonus that adds three to the clock’s tens digit. These paths differ from the manual’s description. The Discoveries tab gives the precise cases.

Ordinary countdown: $57F7. Shared decrement: $5801. Contact branch: $BD63. Ankh: $41DA. Igor: $BD43.

Count Duckula

Every stored room, with the terrain that the movement code reads.

01 · Count Duckula

The pyramid, room by room

Each square above is one world position. The gaps are outside the pyramid. The directory at $FF40 selects a stored page for each occupied square. A room page uses 200 tile numbers in twenty columns and ten rows; the drawing routine turns each number into a 16-by-16-pixel picture.

All 48 room maps are available. This viewer shows their base terrain. Doors, objects, enemies, and Nanny’s later wall changes are drawn by separate routines. The overlay shows the collision values copied into the game’s forty-column terrain buffer. Renderer: $2E53; tile templates: $5C00, $6000, and $6400.

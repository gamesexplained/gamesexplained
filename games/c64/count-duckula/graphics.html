Count Duckula

Every stored sprite shape, plus the pictures and letters that build the screen.

01 · Count Duckula

The shapes behind the actors

Each shape has 63 drawing bytes and one spare byte. A byte holds four pairs of bits. Each pair chooses transparency, one of two shared colours, or the actor’s own colour. The same stored shape can therefore appear in different colours.

Duckula’s walking frames use three consecutive shapes. Mummies and crows use pairs. The viewer keeps each hardware shape separate so their component parts remain visible.

All 104 shapes from pointers $10 through $77 are drawn from $C400 through $DDFF. The game’s shared multicolours are white and black; the menu changes the actor colour. Setup: $2B85. Walking shapes: $3B56.

02 · Count Duckula

The title and its bitmap font

The title logo is stored as a separate bitmap with two colour planes. Text uses eight-byte glyphs. The game writes those glyphs into the bitmap rather than changing a screen character code.

Logo: $1A80, colours $1800 and $1940. Font: $BE50, with colour tables $BE00 and $BE28.

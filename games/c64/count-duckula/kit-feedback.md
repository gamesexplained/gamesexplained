## What cost the most time

A frame-recorder mode that can omit phase-calibration instruction stepping would have avoided two emulator crashes on this installed headless build. Static capture of the unchanged opening display matched every pixel; targeted stopping watches were reliable. The failure is visible, so no skill rule was added.

The health check passed 56 and failed host-key delivery plus an exception in its final quirk probe. Matrix keys, exact stops, stores, reads, snapshots, and frame stepping passed. The run used the installed headless v3.14.0 executable with dummy sound, as requested, and regenerator2000 0.9.20 on macOS arm64. No tools were installed or downloaded. The standard Chromium sound-check command could not start because Playwright was absent. Its exported AudioWorklet checker was run through Firefox BiDi instead: the ten-second theme render had no driver error, nonzero envelope and volume, and a sample span of 1.3294.

1990 · Activision · Commodore 64

Hammerfist

Watch the stored shapes move, inspect their pieces, and rebuild the loading portrait.

01 · animated cast

The player and the component animations

A sprite is a small picture the C64’s video chip can move across the background. The player combines two overlapping sprites, with a third for some weapon poses. Enemies and drops are assembled from their own lists of pieces.

Some pieces join two images vertically. Each image has 21 rows. Timed changes to the chip’s image pointer draw the lower half using the same sprite slot. The viewer uses the stored action tables and their delays. Actor image numbers begin at a separate list, 126 entries into the full bitmap directory.

The actor tables hold the address of each shape and its delay. Their updater at $AD9D compares elapsed game-clock ticks with that delay. The preview advances the clock at the PAL display rate. The primary viewer cycles pose tables without moving through the level. The two “all” choices also show shapes outside these sequences. The shared cache-joining routine is $18A0; the timed sprite updates use $7CD7.

02 · bitmap pieces

Every packed sprite piece

A directory lists where each sprite’s compacted pixel data begins. A short code replaces a run of zero bytes. The directory also tells the mirroring routine whether to reverse single pixels or the wider pixels used in multicolour images.

The four directories contain 279, 279, 271, and 259 entries. All 1,088 entries, both unreflected and reflected, match the original unpackers: 2,176 comparisons. This includes entries that share the same pixels and pieces retained in the payload. The first unpacker is $BEC1.

03 · loading picture

The loading portrait

The portrait appears before the first numbered game load. Its picture survives here as the video bytes needed to draw that screen.

The shared C64 drawing code matches all 104,448 pixels of the VICE reference loading screen. The picture's video memory and register settings are embedded here; the loader program is excluded.

04 · fonts

Characters draw the scenery and the status panel

The room uses eight-by-eight-pixel character pictures as building blocks. The status panel has another character set, with letters, digits, portraits, and meter segments. The game changes the character-set pointer between the two screen bands.

The room’s character pictures begin at $0800. The shared status font begins at $2000. The sheet shows the stored bits in white. The Maps tab applies each room’s colours and character bank. Eleven retained sixteen-row images at $B504 draw digits and a currency sign; their later use remains open.

1990 · Activision · Commodore 64

Hammerfist

Browse the four loads, their room backgrounds, and the tile streams that animate the scenery.

01 · rooms

Every stored room

The game reads four sets of code and graphics from disk. Each set supplies eight rooms selected by its route table, the list of destinations used when the player changes rooms. The docking load also stores two more background records after those eight. Those extra layouts are shown here separately.

These are base backgrounds with each room's selected character bank and palette. Persistent changes, moving platforms, and actors are applied during play. All 34 stored backgrounds match the original tile writer and character-bank exchange: 1,700 tile calls and 34 bank cases. Click a tile to inspect its number and reflection bit.

02 · tile animation

The scenery has its own animation lists

Tile animations change whole four-by-four blocks of characters. Each record names a room and tile position. It then lists tile numbers with timing and control bits. A control bit can send the animation back to its first frame.

The preview repeats a selected stream using its stored delays and the chosen room’s character bank. The game’s state flags decide when that stream runs during play. The original scheduler's room selection was checked for every stored room. Complex 7's animation directory begins at $60A7.

03 · tile format

Sixty bytes describe a background

A room stores five tile numbers followed by one reflection byte for each of ten columns. The reflection byte supplies one bit per tile. The tile writer then reads tables for the sixteen character pictures and their colours to fill the screen.

Colour numbers from 8 through 15 select multicolour characters. Each pair of image bits then becomes a wider pixel. Other colours select single-pixel characters. The set of character pictures can change from room to room even when a character number stays the same.

The first room record is $3C2F in Complex 7, $3C37 in the docking load, $3C27 in the third load, and $3B2F in the fourth. The first-load tile writer is $C300.

First-room gameplay references: Complex 7, docking area, third load, and fourth load. These include runtime objects and changes beyond the base maps.

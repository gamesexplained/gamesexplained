One suit of Power armor can protect the whole party, and a shop sells back whatever the Rangers sold it, in another town if need be. Below them is every item in the game, with where it is found, who sells it, and what it is good for.

01 · Armour

Bug: one suit of Power armor can protect the whole party

A Ranger's armour class is a number the game writes down when the armour is put on, and it takes the number away only when the item it has marked as worn leaves the pack. Sorting the pack with one stray press of RETURN moves that mark onto the wrong item. The suit can then be traded to the next Ranger, and the first Ranger keeps its armour class.

The party

    The game's item list appears here.

    Four Rangers on the game's own code. Each button types keys into the game's item list ($0FB1) and the screens the game prints come back as text, with the line the game shows in reverse video picked out. The Ranger who is handed the suit puts it on with unE)quip.

    Power armor is the best armour in the game. A Ranger who wears it rolls 14 dice against every blow and takes that much off the damage, which is 49 points on average. Seven suits lie in bags late in the game, one recruit carries an eighth, and no shop sells one.

    The game keeps two numbers for a Ranger's armour. One is the line of the pack that holds the armour being worn. The other is the armour class, which the game copies from the item when the Ranger puts it on ($10C9). Every blow in a fight reads the armour class and never looks at the pack ($A8B2).

    The armour class goes back to 0 when the worn line is emptied. Dropping an item, trading it, selling it, or using it up all end by asking whether that line was the worn one ($10D8). If the line is the worn one, the game clears both numbers. If the line is any other, the game leaves the armour class alone.

    Sorting a pack is where the two numbers come apart. R on the item list starts a reorder: the player picks the items one at a time, and the pack is rebuilt in that order. The game counts the picks so that it can note which new line the worn armour lands on. RETURN, space, R, and the back-arrow pick nothing, but the count goes up for each of them all the same ($1015). After one such key, the note for every item picked later is one line too low.

    So a Ranger in Power armor sorts the pack and presses RETURN once before picking the suit. The suit keeps its armour class of 14, and the worn mark sits on the item below it. The suit is now an ordinary item that can be traded away, and the trade asks about the suit's own line, which is not the worn one. The next Ranger puts the suit on and does the same. The plate ends with four Rangers at armour class 14 and one suit between them.

    The armour class is part of the saved game, so it lasts. A Ranger loses it by putting on other armour, or by losing the item that carries the mark: a Canteen that is dropped takes the armour class of 14 with it.

    02 · Weapons

    Bug: sorting a pack can leave a Ranger holding a clip in place of a gun

    The mark for the weapon in a Ranger's hand goes wrong in the same way as the armour mark, and the weapon mark matters at once. A Ranger whose mark has slipped down a line fights with whatever is on that line. A Ranger with nothing in hand can be given a weapon mark by another Ranger's sort.

    The party

      The game's item list appears here.

      The same item list as above. The first Ranger holds a pistol, and the second holds nothing and fights with fists. Neither sort changes the order of the pack.

      The first button sorts a pack without changing its order, with one press of RETURN before the first pick. The pistol stays on line 1 and the game notes line 2 for it. The Ranger now holds the 45 clip. The game lets a Ranger hold anything that is not armour ($10A2), so nothing complains. In a fight the clip is swung by hand for one die of damage, where the pistol fired for four.

      The second button shows the other way the mark goes wrong. The game writes the line it noted for the weapon into the Ranger's record when the sort ends ($1023). It never clears the note. A Ranger with nothing in hand picks no weapon, so the note still holds the line from the last sort that moved one, by any Ranger. The bare-handed Ranger ends the sort holding whatever is on that line of their own pack.

      This costs a Ranger who fights with fists more than it seems. Fists are the one weapon that Pugilism helps with, and a Canteen in the hand is not fists. The Ranger hits no harder with the Canteen and loses four points on every attack roll for each level of Pugilism. The note starts at 0 when the game is loaded, so the first sort of a session is safe for a bare-handed Ranger.

      03 · Shops

      Secret: what the party sells in Quartz goes on sale in Needles

      A shop keeps a count of every item, and the count goes up by one whenever a Ranger sells it that item. Anything with a count above 0 is on the shelf, so a shop sells back whatever it was sold. The Emporium in Quartz and Leroy's arms counter in Needles read the same counts, so what is sold to one can be bought from the other.

      Hell Razor

      The shelf the two shops share

      The shop's screens appear here.

      The shop program ($CA00) on the game's own code, with the shop records of Quartz (map 1) and downtown Needles (map 32). The buttons type the keys. The counts are the ones on side 2 of the game disk.

      Every item has a stock count beside its price. A sale adds 1 to the count ($CB2C) and a purchase takes 1 off ($CC12). The buy list shows every item whose count is not 0 and whose kind the shop deals in ($CC5D). No shop starts with Power armor, but a shop that has been sold one has a count of 1 and lists it, at the full price of $30,000.

      The counts are kept in four files on the disks, and each shop's record names one of them. The Emporium and Leroy's counter both name file 2, and both deal in every kind of weapon, armour, and gear. They are one shelf with two doors. The same is true on paper of the two shops in Darwin and of the Trading car and the Agricultural Center's store, but those pairs deal in different kinds of item, so neither can show what the other was sold.

      A count stops at 255 when it goes up and has no floor when it goes down. The items a shop stocks from the start have a count of 255, which looks like a mark for endless stock and is treated as a plain number. Each purchase takes one off. A party that buys 255 Jugs at $1 each has bought the last Jug that shelf will ever hold, unless somebody sells one back.

      04 · Shops

      Bug: an item sold just before the machine is switched off is in the pack and on the shelf

      The shop saves its shelf and the party at two different moments. The shelf goes to the disk as soon as a Ranger leaves the list of things to sell. The party is saved only when the Rangers leave the shop. Switching the machine off between the two leaves a game in which the item was sold and was never given up.

      Hell Razor

      On the disk

      The shop's screens appear here.

      The Emporium in Quartz on the game's own code. In place of a disk drive, the page keeps what the game writes: the shelf when the game calls $26D6 and the party when it calls $18EA. Switching off puts back the party as it was last saved.

      Leaving the sell list writes the shelf to the disk at once ($CB51). The sale is then on the disk for good. The Ranger's pack and money are still only in memory. The shop saves the party when the player presses the back-arrow at Who wants to enter? ($CA85).

      A machine switched off in between loads the last saved game, in which the Ranger still has the item, and finds a shelf that has one more of it. The money from the sale is gone with the rest of what was in memory, so the second suit still costs its full price. What the party gains is a second copy of something no shop would otherwise sell: Power armor, a Meson cannon, or a Proton ax.

      A Ranger who travels alone has longer to do it. The shop skips Who wants to enter? for a party of one, and that Ranger leaves by the back-arrow at B)uy or S)ell?, which goes past the save ($CA98). The game saves by itself the next time the party changes map.

      05 · The list

      Every item in the wasteland, with the numbers the game never shows

      The game shows an item's name, and a shop shows its price. Each item also has eight bytes that say how hard it hits, how many shots it holds, what loads it, and which skill it uses. The table has all 95, with the bags that hold each one and the squares that take it. Press a row for the rest.

      ItemKindPriceDiceHoldsSold byFound

      Dice are six-sided: a weapon's damage, or the dice a suit of armour takes off each blow. Holds is the rounds in a full gun, or how many times a thing can be used before it is gone. Found counts the bags on the 42 maps that hold the item when the game starts.

      06 · Loot

      Secret: ten bags under the Temple of Blood roll their ammunition when they are first opened

      Almost every bag in the game holds what its map says it holds. Eleven bags name a kind of item instead, and the game picks the item when a Ranger first opens the bag. All eleven name ammunition. One time in five the pick is Power packs, which no shop sells, and one time in five it is Howitzer shells.

      This bag

      Not opened

      Bags opened

        Each bag's ammunition appears here.

        Bag 1 under the Temple of Blood (map 28) on the game's own code ($9194), put back as the disk has it before each opening. The random bytes come from this browser, where the C64 reads its raster line and a timer.

        A bag is a list of pairs: an item and how many. When the item byte is a kind of item, the game counts the items of that kind, rolls a number up to the count, and writes the chosen item into the bag ($91C8). The roll is fair, so each of the five kinds of ammunition comes up as often as the others: 45 clips, 7.62mm clips, 9mm clips, Howitzer shells, and Power packs. The number of them is rolled too, from 1 to 7.

        The game makes the roll once. It writes the result into the map, and the map goes back to the disk when the party leaves, so a bag that has been opened holds the same thing ever after. Until the party leaves, the disk still has the bag unopened. A party that does not like the roll can switch the machine off, come back, and open the bag again.

        Ten of the eleven bags are under the Temple of Blood, and each also holds a weapon and some money. The eleventh is in the Las Vegas sewers and rolls from 1 to 10 of its ammunition. The game's code would roll any kind of item this way, and the maps only ever ask it for ammunition.

        08 · Guns

        Secret: reloading a gun throws away the rounds that were left in it

        A gun's rounds are one number in the Ranger's pack, and the game only ever sets that number to full or to nothing. A reload does not top the gun up. A jam costs every round in the gun.

        What happensRounds in the gun afterwardsWhere
        The Ranger reloadsA full clip, whatever was left. One clip is used up.$1281
        The gun jams in a fightNone. The rounds are lost with the jam.$A5B5
        The Ranger clears the jamNone. The gun needs a clip before it fires again.$153E
        The gun is bought, or taken from a bagA full clip.$CBFD, $928C
        A recruit joins the partyEvery gun the recruit carries is filled.$A47A

        The M1911A1 pistol holds 7 rounds. A Ranger who reloads with 6 left has spent a 45 clip to gain one round. The game asks Reload (Y/N)? whenever the Ranger picks a clip that fits the gun in hand, and it does not look at how many rounds the gun has.

        The Flamethrower is the one gun that cannot be reloaded at all. Its record names no ammunition, so the game never offers a reload, and its 60 shots are all it will ever have. It is also the one weapon that no skill helps with. Selling an empty Flamethrower for half its price and buying a full one is the only way to fill it.

        10 · Left in the table

        Items that are in the table and never reach the player

        Three of the 95 items have prices and no names. Two others sit out of alphabetical order in a list that is otherwise sorted, which is what a renamed item looks like. One rifle rolls 200 dice and is in none of the bags.

        20Red Ryder$12,345A rifle with 200 dice and 63 rounds, loaded with 7.62mm clips.

        The quest items, 58 to 90, are stored in alphabetical order: Android head, Antitoxin, and on through the keys and the Secpasses to Toaster. The three items with no names are 70, 71, and 72, between Grazer bat fetish and Nova key, so their names began with a letter from G to N. Item 70 is the odd one. It holds 5 charges, rolls 3 dice, and is loaded with Power packs, which makes it a small energy weapon that was filed with the quest items.

        Two names break the order. Finster's head is between Antitoxin and Blackstar key, and the Visa card is between Clone fluid and Fusion cell. Each fits its place under some other name: a second head beside the Android head, and a card whose name began with C, D, E, or F. What those names were is not on the disks.

        The Red Ryder is a rifle with 200 damage dice and a price of $12,345. It is not in any bag, on any recruit, or on any shelf, and it has a section of its own. There are also two Bloodstaffs, items 62 and 63, with the same name and the same eight bytes. Seven bags hold one and four hold the other, and every square that takes a Bloodstaff takes either.

        The last record in the table is called Cash and is not an item. A bag's money is marked with its number, 94, and the game treats that number as money wherever it meets it. The eight bytes of its record are whatever lay after the table when each file was made, and they differ from file to file.

        11 · The record

        How eight bytes make an item

        The item table starts at $3108 and gives each item eight bytes. A shop loads its own copy of the table over the one in memory, and the copies differ only in the stock counts.

        ByteHoldsRead by
        0-1The price. A shop sells at this price and pays the price less a half or a quarter of it.$CD18
        2The stock count of the shop file that is loaded: 0 for not sold.$CC6A
        3The kind of item in the top five bits, 1 to 18. The low three bits are 1 for the seven explosives and rockets, which shake the screen when a Ranger uses one on a square.$144A, $1454
        4The rounds in a full gun, or the number of uses. An item with 0 here is never used up: a Crowbar, a key, a Secpass. An item with 1 is gone after one use: a Rope, a rocket, a Fruit.$1470, $14A5
        5The skill that adds to the attack roll and that the weapon can teach, or 0 for none.$0DD0
        6The damage dice of anything held in the hand. For armour, the armour class.$146D
        7The item that reloads a gun, or 0.$AC39

        A Ranger's pack is 30 pairs of bytes: an item number and a count. The count holds the rounds left or the uses left, and its top bit marks a jammed gun. The game never stacks items, so ten 45 clips take ten lines.

        A bag on a map is a list of the same kind of pair, with one difference: the count is how many of the item the bag holds, and a count with its top bit set is rolled from 1 to that number when the bag is first opened. Money is the pair's item number 94 followed by two bytes, and each byte is rolled on its own from 1 to its value. A bag whose two bytes are 232 and 3 is not worth from 1 to 1,000 dollars. The low byte is rolled from 1 to 232 and the high byte from 1 to 3, so the bag holds from 257 to 1,000 dollars and never a number that ends between 233 and 256 above a multiple of 256.

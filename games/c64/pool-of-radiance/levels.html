1988 · SSI

Pool of Radiance

The 29 maps on the game's disks, each a block of 16 by 16 squares, drawn from their files.

01 · Every map

Every map on the disks, square by square

The game loads a block's map into memory at $0400 (an address in the C64's memory, written in hexadecimal) when the party enters it, together with the script of the same number that decides what happens there. Every map file on the eight disk sides is drawn here.

‹›

Click a square.

White lines are walls, a gap with yellow ends is a door that opens, and red is a locked door, read from the map's four pages as the How it works page explains (the maps). North is at the top. A wall is drawn on every side of a square that has one, so a wall that is there on one side only looks the same as one on both. The line beside each map is from its script; a name is given only where the script names the place.

MapDiskIts script says

The map files GEO1F and GEO20 have no script of the same number on any disk side, and GEO1E is the map of the demonstration the title menu runs. Three scripts, ECL08, ECL0B and ECL13, have no map file of the same number.

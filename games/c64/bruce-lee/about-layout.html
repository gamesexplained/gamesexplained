About this page

The copy studied

The pages describe a disk cracked by the group Remember. Its own code runs first: an intro, a text page, the loading picture, and two trainer questions, then a loop that moves the game’s start-up block to $0400 and jumps to it. Everything on these pages is the game as it runs after that hand-over, with both trainers answered “no”. The game calls itself REV.2 in its hidden version line ($4707). Which bytes the crack or its trainers change was not worked out, so a detail here may differ from Datasoft’s original disk.

The Source tab’s listing is built from memory saved with Bruce standing in the first room. No game image is hosted here.

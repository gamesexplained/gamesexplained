The game is a 6502 program of about 47,000 bytes in eleven files that load over each other. The port is the same program written again in JavaScript, one function for each routine the listing names, 599 in all, reading and writing the game's variables at the game's own addresses.

The page carries the game's data files whole and its code files with every instruction set to zero, apart from 3,157 bytes of instructions the game rewrites and reads as variables.

The port executes no instructions, so the page charges each stretch of the main loop the cycles that stretch costs the game, and keeps within 2 % of the game's pace.

• No loading time. The 1541 takes seconds over each file; the page has every file of both sides at once.
  • No hang at "Old or New Game?". The routine that turns on the bitmap leaves the raster interrupt set for line $150, which a frame never reaches, so about one start in six on a PAL machine stops there for good (Discoveries). The page moves the line back into the frame, as the simulator the port was checked on does.
  • Saves stay in this browser. Saving in space writes the game's SAVED file to the browser's storage, and an old game loads it from there. A browser that keeps no storage for the page keeps the save only until the game is started again, and an old game with no save of the player's loads the one on the original disk.
  • The manual's word is on the page. Before an old game the game asks for a word from a page of its manual. The page shows the word the game wants under the screen.
  • Interrupts between stretches. On the C64 the frame's interrupt can come between any two instructions; on the page it runs between two calls of the main loop. Where the main program reads what the interrupt counts in the middle of a call, the page first moves its clock on by what the call has cost so far, so the count includes the frames the drawing took, as on the C64.
  • Keys held for three frames. The game reads the keyboard once a frame, so the page holds a key for at least three frames however briefly it is tapped.
  • Sound a frame at a time. The site's model of the sound chip takes each frame's register writes together, in the order the game made them.

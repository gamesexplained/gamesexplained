01 · Play

Fly the patrol with the keyboard

The arrow keys are the joystick in port 1 and Z or Enter is its fire button. Fire on the title screen starts a game, and fire again starts each strafing run and each new level. Left and right turn the landscape under the plane, up climbs and down dives. After the last life the score goes into the highscore table, where the stick picks each letter of the name and fire takes it.

02 · The port

Every routine of the game, written again in JavaScript

This page does not emulate a 6502 to play the game. The game is written out in JavaScript in reference/hp-port.js, one function for each routine of the listing, and runs on the game's own 64 KB, loaded from the bytes the Source code tab shows. Every variable stays where the game keeps it: the lives at $40, the level at $44, the kind of defence at $41, the ground objects' records from $80C0. The one part that runs as 6502 code is the title tune, which is the game's own music player, run as the Music tab runs it.

Some of what the game reads cannot be worked out from memory. Its random numbers come from CIA 1's timer, from the raster line and from voice 3 of the SID, set to noise; its hits come from the video chip's sprite collisions, which it gathers in the interrupt that draws each band of the screen. On the page the timer counts down on the page's own clock, the noise is the SID's 23-bit shift register stepped as the voice runs, and the collisions are the site's model of the video chip, which works them out pixel by pixel as the clock moves. The page and the game draw different random numbers, so the same input plays out differently on each.

The page keeps the C64's pace by keeping its clock. Each stretch of the game's work costs the cycles it costs on the C64, measured against the game's own code; the delay loops count their cycles as the port reaches them, and the waits for the raster run the clock to the line. The interrupts come on their lines, and the music's on the timer, every 18,433 cycles.

test_play.js runs the port beside the game's own code on the site's model of the C64, from the same start and with the same input, and compares their memory, colour RAM and chip registers at every checkpoint: through every kind of defence, the strafing runs and all four levels, the game over, the name entry, the cracker's highscore saver and the game from the start again.

About this page

The copy studied

The pages describe a disk image of the game cracked by Remember (REM), with a trainer menu, a highscore saver and a set of text pages added in front. A BASIC line at $0801 starts a packed program, and the game is unpacked into memory before the cracker's menu appears. The listing is built from memory saved in steady play. The cracker's code is not Mastertronic's, and the Source tab marks it where it was found. Whether the uncracked game differs was not checked.

No game image is hosted here.

About this page

The copy studied

The pages describe Elite Systems' 1988 disk, as a G64 image. A short boot program loads a fast loader, which shows the loading picture and reads the game from sectors that no file names, then starts it at cold_start. The game is one load: nothing is read from the disk again. The listing on the Source tab is built from memory saved at that moment. No game image is hosted here.

Data East's American disk of 1987 was also looked at. It is a different program, by Quicksilver Software, and only its screens appear here, for comparison on the Overview.

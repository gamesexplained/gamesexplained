# Jumpman: controls and controlled experiments

Speed keys 1–8 are ordinary controls. They change the requested speed immediately, but the next life applies it. This was verified live by choosing1 while the active divider remained4, then following the native respawn to divider1.

The analysis used disposable saved states to test score thresholds, bonus subtraction, ranking and a final-award overflow. Those experiments establish the routines' behavior; they are not input sequences or verified routes to those states. No additional cheat code or player exploit is claimed.

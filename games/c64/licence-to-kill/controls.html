Commodore 64 · 1989 · Domark

Licence To Kill: controls

One joystick in port 1, a different meaning for it in every scene, and two keys.

01 · The joystick

Port 1, and nothing else

The game reads a joystick in port 1 only ($8206 reads port 1's register, $DC01). Fire on the title starts a game; a joystick in port 2 does nothing.

The flying scenes share one routine, steer_player. Pushing the stick does not move the helicopter straight away: each direction builds up speed through a counter and dies away again when the stick is let go, so the helicopter drifts.

02 · The keyboard

RUN/STOP to pause, Q to give up

RUN/STOP pauses the game (pause_keys). While it is paused, any movement of the joystick or fire carries on, and Q ends the game and goes to the high-score table. The countdown stands still while the game is paused.4

A score good enough for the table asks for a name, "GREAT SCORE. INPUT YOUR NAME.": up and down change the letter and fire moves on to the next of the three (name_entry). The table is kept only in memory and is lost when the machine is switched off.

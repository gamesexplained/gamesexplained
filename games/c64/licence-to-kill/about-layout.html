About this page

The copy studied

The pages describe a disk image of the game that was made with a freezer cartridge: the Trilogic Expert saved the whole of memory in the first second after the game had started, and a fast loader called BOND puts it back. The listing on the Source tab is built from that memory, resumed at the program's first instruction, $07F8. A second disk image holds another freezer backup of a different build: the same program with 16 bytes added at its start, so almost every address in it is 16 higher, and identical graphics. These pages do not describe what else the second build changes.

No game image is hosted here.

Original game credits

The game's title pages credit Chris West for the Commodore 64 version, Tony West for the graphics, David Whittaker for the sound, and John Kavanagh for management, and name the programmers of the Atari, Amiga, and IBM versions. The game's text also says "BY QUIXEL", the team Zzap!64 named as the authors of the C64 game.1 Domark published it in 1989.

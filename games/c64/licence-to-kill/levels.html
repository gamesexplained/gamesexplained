Commodore 64 · 1989 · Domark

Licence To Kill: maps

The scenery of all five levels, drawn from the game's own map rows, tiles and character sets.

01 · The maps

Five maps, read from the bottom up

Four of the five levels scroll: the scenery moves down the screen and Bond flies, swims or drives up it. Level 2's gunfight in the boatyard scrolls only as Bond walks up it. Each map is drawn here as one long strip, with its start at the bottom, where the level opens.

A map is a list of rows, four bytes to a row and one byte to a tile. A tile is 8 characters wide and 4 high, so a row of four tiles fills the 32-character playfield. The game reads the map backwards, from its last row towards an $FF row at its start (draw_new_map_row), drawing one character row of the tiles at the top of the screen each time the scenery has moved down by 8 pixels (copy_tile_row). The last seven rows of each map do a second job: before the level begins, draw_picture_tiles draws them whole as the opening picture.

Colour comes from two places. Each tile number has an attribute byte. When a row's first tile names a different colour scheme in its attribute's low four bits, the two colours every character shares change from that row on (map_row_tiles); the change is a raster split that moves down the screen with the scenery (move_colour_splits). When an attribute's top bit is set, its top four bits are a colour for that tile's column of the screen, painted into colour memory a row at a time as the tile moves down (row_colour_patches). The drawing here applies both from the row they start at.

Discoveries

A disk-side message in the copied code

The Censor disk retains two copies of a three-row message in the story code:

          please turn disk over

      press fire button when ready

The message routine copies 120 bytes to the screen area. Two routines use the filename SIDE FLAG and read a byte after a load. The checks at $11A2 and $11DE would display the messages and repeat the read under their respective conditions.

In the captured code, the two setup paths jump over those checks. This describes the Censor release examined here; it does not establish how other releases behave or whether another route reaches the checks.

The source listing shows the stored bytes under I/O at $D000. Before this code runs, the game copies them to the addresses beginning at 0x1000.

A test row in the story code

The same stored block contains a 40-byte row with the words “this is just some test text!”, followed by a zero byte. The listing shows the row and its padding. Whether the game ever displays it remains open.

Museum movement skips eight overlap checks

The museum code contains blocks that compare two position records. When their comparisons match, the blocks return before a movement update. In the examined Jondi disk, each of eight movement paths contains an unconditional jump over one of these blocks. For example, $B7FB jumps to $B833, past the comparison at $B7FE.

The eight jumps are present in the museum entry snapshot and four later saved states. Other possible entries into the skipped blocks have not been ruled out. The damaged Censor museum file does not provide a complete comparison, so the reason for the jumps and their behavior in other releases remain open.

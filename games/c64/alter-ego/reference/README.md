# Reference material

- `first-prompt.png`: the contributor's picture of the first prompt for the player's name, drawn from the snapshot stopped there.
- `name-input-limit.png`: the name line with sixteen letters typed, the most it takes.
- `old-age-last-scene.png`, `stage-over-menu.png` and `new-life-womb.png`: the end of a life on the kit's C64, the game's own code alone. Old Age chosen at the start and played by keys at random (seed 7) ends at the age of 70: the life's last scene, then the menu that ends every stage (where the keys took SAVE GAME, then Cancel), then the first page of a new life in Infancy.
- `adolescence-welcome.png` and `adolescence-map.png`: Adolescence chosen at the start on the kit's C64, the game's own code alone: its first page, then its map with the arrow, the scenes' pictures down the middle and the choices in the columns beside them.
- `months-before-saving.png` and `months-after-resuming.png`: the LIFE TIME screen on the kit's C64, the game's own code alone. Infancy played from a new life until a scene has moved the year on to 0 years and 3 months (the fraction at `$7FC4` reading `$4703`), then saved in the first place and quit; then the machine started afresh and that life resumed from the start's menu, which shows 0 years and 0 months.
- `import-audit.json`: the record of the contributor's analysis brought into the kit: the source's hash and the checks made on it.

The pages carry only the data their widgets show.

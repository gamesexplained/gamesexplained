• Fast. With the switch on, a frame in which the game does not look for a key is followed at once by the next, until it looks for one again. The frames are the game's own, one after another, and its clock and interrupts run as on the C64, so the game does what it would have done; it is only not waited for. A page that takes the C64 one to ten seconds, unpacking its words, drawing them off the screen and bringing the page down a pixel row a frame, appears as soon as it is ready. While a key or the stick is held, Fast waits for it to be let go: the arrow glides between its moves, and a stick held through frames run at once would send it on past the answer. The sounds of a stretch run at once play together, as it ends.
  • All six disk sides in the drive. When the game asks for another side, any key goes on. A record of a file comes the moment the game asks for it, where the 1541 takes about a tenth of a second.
  • Saves stay in this browser. A game saved from the RUN/STOP menu goes to the browser's storage, and RESUME A SAVED GAME finds it there. A browser that keeps no storage for the page keeps the save only for the visit.
  • QUIT starts the game again. On a C64, QUIT resets the machine. The page starts the game again from the moment the loader hands over, with the disk as it was left.
  • Interrupts between routines. On the C64 the timer's interrupt can come between any two instructions; on the page it comes between two of the port's routines, at the cycle it falls due.
  • Keys held for three frames. The KERNAL reads the keyboard once a frame, so the page holds a key for at least three frames however briefly it is tapped.
  • Sound a frame at a time. The site's model of the sound chip takes each frame's register writes together, in the order the game made them.

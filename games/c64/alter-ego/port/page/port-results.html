The game is about 40,000 bytes of program in three loads: the resident program, with the interpreter that runs the rest, the start and the life object. Most of it is p-code, a program compiled for a stack machine. The port is that program written again in JavaScript, routine by routine, reading and writing the game's variables at the game's own addresses.

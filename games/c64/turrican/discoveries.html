1990 · Rainbow Arts · Commodore 64

Turrican

Two bugs any player can meet, and the messages, names and leftovers that the game keeps where no screen shows them.

01 · pause and fire

Bug: Holding pause and fire, the hero walks through a level with no enemies

CTRL pauses the game for as long as it is held. While it is down, the main loop sets the pause flag ($0203) again every time round ($08EA). Fire clears the flag ($0B48), but only for the first half of each frame. In that half the hero moves, the time counts down and the view scrolls. By the time the interrupt near the bottom of the screen runs the enemies ($0CAB), the flag is set again, so no enemy is made and none moves.

Both pictures start from the same moment in level 1-1. On the left, the hero walked right for six seconds, and ten of the eleven object slots filled with enemies. On the right, CTRL, fire and right were held for the same six seconds. The view scrolled to exactly the same place and the time counted down the same, but no enemy appeared.

02 · the loading tune

Secret: The loading tune checks its own credit line, and goes wrong if it is changed

The tune that plays while the game loads has a player of its own, Romuzak V6.3 by Oliver Blasnik. The player carries a line of text: “ROMUZAK V6.3 <W> BY OLIVER BLASNIK, <C> DIGITAL MARKETING!!”, followed by a telephone number. While the tune plays, the player reads that line one byte at a time and combines each byte into a check value with EOR. At the end of the line it compares the result with $56, the value the line as written gives.

When the line has been changed, the player keeps the wrong value and adds it to two bytes of each voice’s state every 1,024 frames (the boot’s code at $D9EE and $D9D5). A cracker who wrote their own name into the line would hear the tune go wrong about 15 seconds in, and lose most of its notes after that. Both buttons run the player’s own code on the kit’s 6502. The second has one letter of the line changed.

On the 6502, the changed tune first differs at frame 769, about 15 seconds in. In the next minute it starts about a quarter as many notes as the tune as stored. Changing a byte of the line in VICE while the tune played set the wrong value at $808F the same way. This site leaves the telephone number out: ten of its digits are replaced, with values chosen so that the line’s check still comes to $56 and the tune plays as it should.

03 · the hall of fame

Bug: A player who finishes the game is listed at level !-!

When a game ends, the engine copies the name of the level reached from two bytes of the level’s file in memory, $8CA2 and $8CA4 ($0957). In every level they hold the level’s own name, such as 1-1. After the last level the ending’s file is in memory instead, and at those two addresses it holds two bytes of the picture of the tower, $65 and $55. The title shows each of them as an exclamation mark (title $7087), so a player who finishes the game is listed at level !-!.

04 · no name

Secret: Pressing RETURN without a name enters MR. RETURN

A player who presses RETURN without typing a name goes into the hall of fame as ♥ MR. RETURN ♥ (title $7CE2). The picture above shows him at the top of the table. The hearts are character $1E, which is an up arrow in the machine’s own characters and a heart in the title’s font.

05 · the first table

Secret: The hall of fame starts with the team’s names and a copyright line

Before anyone has played, the hall of fame lists the people who made the game. Manfred Trenz is at the top with 100,000 points and level 4-2. Its last three rows spell out a copyright line instead of names. The table below is read from the engine’s listing ($6860, loaded from the file IH). In the picture above, the line’s last row has dropped off the bottom of the table.

06 · to crackers

Secret: A message to crackers is in the title’s file, and nothing prints it

The title’s file holds 842 characters of text that no code reads (title $94A6-$97EF). It is Manfred Trenz writing to whoever would crack the game:

HI FOLKS, THE MANIAC IS BACK !!! ONE QUESTION: WHY DO YOU WANT TO CRACK THIS PROGGY ??? CAN YOU IMAGINE HOW MUCH WORK I DID TO MAKE A GAME LIKE THIS ??? HERE SOME INFORMATIONS ABOUT: STARTING TIME: 01.02.1989 (OH YES) ALL THE IDEAS,GAMEDESIGN,ALIENROUTINIES,GRAPHICS,PLAYBILITY,TECHNICAL PROBLEMS AND MUCH MORE TOOK A LOT OF TIME AND WAS VERY OFTEN NERVE-RACKING! ECHT AETZEND YOU WOULD SAY ... SOMETIMES I WORKED MORE THEN 14 HOURS A DAY, ONLY INTERRUPTED BY ESSENTIAL THINGS LIKE FOOD,COKE AND MTV. I MADE THIS GAME NOT ONLY FOR MONEY BUT NEVERTHELESS I'M SURE YOU AGREE WITH ME, THAT I WANT TO EARN FOR MY WORK. SO DO ME A FAVOUR AND DON'T CRACK AND SPREAD THIS GAME !! IF YOU HAVE ANY QUESTIONS, CALL: [a telephone number] BYE NOW AND THINK ABOUT ! PS.: DO YOU KNOW WHAT A GROELAZ IS ??? YOU BETTER DO NOT !!

“Echt ätzend” is German slang for “really awful”. The credits that the title does show are stored scrambled: each byte is changed with EOR and a key that grows by one step a byte, and the title decodes them when it starts ($7BAB). A search of the file for a name in the credits finds nothing.

07 · the ending’s credits

Secret: The ending’s credits name the disk loader and the protection

The title’s credits name a producer, three musicians and the authors of the sound routines. The credits at the end of the game are shorter and different. They name one musician, Ramiro Vaca. They add two people the title leaves out: Markus Wiederstein for the disk loader, and Alexander Ernst for the protection. Alexander Ernst is also in the first hall of fame. The text ends with “Now enjoy the music or Press Space”, and under it “The End ....??” (the ending’s text, $707E-$75B6).

08 · saving

Secret: A failed save answers in German: DANN EBEN NICHT !!

S on the hall of fame asks for side 1 of the disk, to save the table on it. When the save fails, the screen turns light red and says DANN EBEN NICHT !!, German for “never mind, then” (title $7546, the text at $923C).

09 · the speech

Secret: The spoken sample has a disk command inside it

While the game loads, the boot plays a short spoken sample through the sound chip’s volume register. Inside the sample’s bytes, twice, is the text S:THEMARKUSMONSTER (at $A0FA and $A30C in the boot’s memory). S: is the disk drive’s command to delete a file, here a file called THEMARKUSMONSTER. The text is played as sound, with the rest of the sample.

10 · leftovers

Secret: Three files carry text that nothing reads

Level 4-2’s file ends with 179 bytes that no code reads, holding the text TUSL.4-2 and 4-2. The title’s file holds DTE+DTZ+ACU+MWS+AV IN 1990 ($C610), which no code reads either. The boot program is called SCHLUMPF, German for smurf, and carries the text TRALALA !!.

Impossamole

Five level payloads replace the landscapes, creatures, and character graphics while keeping the same engine.

Every stored landscape

Each level stores 424 columns of blocks, with six blocks in each column. The picture below draws that whole allocation. Exits can redirect the view into another part of the stream. A position in this picture does not by itself establish that Monty can reach it.

Scroll sideways through all 1,696 character columns. The same block renderer is tested against $5192 for all 256 block IDs in all five payloads. Colours come from $AE00 and the level’s shared colour tables.

Exits choose another view

The exit handler at $3096 matches an edge and a source position. Each record supplies a destination scroll value, right scroll limit, and Monty’s destination X. The game computes the map pointer from that scroll value at $50E3.

The destination preview uses the stored scroll value rounded down to a four-character block boundary. It shows map data, without actors or the transition animation.

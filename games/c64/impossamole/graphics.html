1990 · Gremlin Graphics · C64

Impossamole

Numbered actor recipes select colours and timing. Lists of shape numbers make the pictures move.

Actors follow their own animation records

Actors are Monty, creatures, attacks, and collectable objects. Templates are the game’s numbered recipes for creating them. Each one gives a starting shape, colour, collision size, and animation timing. The viewer uses the 26-byte records addressed by $817C. The viewer follows $3C32, the routine that creates an actor from a level spawn record. That routine leaves its picture at normal width. A second creation routine, $4F04, instead takes horizontal expansion from record byte 6. Expansion makes the picture twice as wide.

The animation routine $382B counts the delay down to zero. It then reads another shape number from $8EC0. A marker can return to an earlier point or remove the actor. A delay of n leaves n+1 calls between shape changes. The viewer advances about 50.125 times per second, the PAL C64’s frame rate. Its results match the original routine run on a model of the processor.

Monty has a separate shape stream

Monty’s movement state and facing choose a starting position in the list at $7EF9. The normal animation counter reloads to five. The marker $80 says that the following number is another position in the list. Gun weapons select alternate shapes by adding $16 to a shape below $17, as $13A7 does. Turning and standing on a ladder add conditions to normal play; this viewer keeps each selected sequence running.

Shapes outside those animation streams

The selector contains the shapes that the viewers above do not animate for this level. It includes fixed objects and spare slots. Their role is left unnamed when a shape number alone cannot establish it. The colour and multicolour controls are inspection settings. Multicolour mode groups each pair of bits into one double-width pixel. Each actor’s stored settings choose the mode in play. Every one of the 160 sprite slots is represented by an animation or this selector.

Characters supply the scenery

The level character set contains 256 eight-byte shapes at $F000. A character’s colour chooses between a one-bit pattern and double-width multicolour pixels. The sheet uses the level’s colour table. The map combines these shapes into four-by-four-character blocks.

The rebuilt frame shows how interrupts, scheduled processor calls, switch character sets during drawing. The title image is shown on How it works. The selected disk begins with a crack intro rather than a separate original loading picture.

About this page

The copy studied

The pages describe Domark's disk, as a G64 image. The game is two loads. The first, TITLE, is the introduction: the title picture with the scream, the licence, the story, and the portraits. It loads the second, TITLE2, which loads the game's files and starts play at game_start. Each load has its own listing on the Source tab, built from memory saved once it was running. One sector of the disk has a bad checksum; the game boots and plays all the same.

A cartridge conversion made in 2025 was compared with the disk byte for byte. Every byte of the game's code and data is the same, apart from values the game writes while it plays, so both come from one release. Neither says whether that release is the original or a crack. The cartridge leaves out the introduction's code, its licence and story, and the portraits.

No game image is hosted here.

Original game credits

The game names nobody: no credit is shown on screen or stored in either load, and none of the sources below names a programmer, artist, or musician for any version. Domark, founded by Dominic Wheatley and Mark Strachan, published it.1

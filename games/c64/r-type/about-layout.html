About this page

The copy studied

The pages describe the tape release, version 1, as cracked to disk by the group Oneway, whose title card reads R-TYPE++. The crackers replaced the tape loader with a disk loader and added a key that wins the stage at once (Discoveries). The collision check that the C64-Wiki gives for tape version 1 is at the same address in this copy (kill_ship, $319C).

The game is ten loads: the resident program with the title screen, eight stages of three files each, and the ending. Each has its own listing on the Source tab, built from memory saved while that load was running, and the addresses on these pages are those of the load named beside them. The routes to each stage used the crackers’ key.

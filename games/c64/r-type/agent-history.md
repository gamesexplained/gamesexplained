# R Type — agent history

Narrative of how the analysis went, including wrong turns, for the next
agent's benefit. This is the only file that narrates; `facts.md` and
`features.md` state current truth only.

## 10 November 2026

Orient and parts went quickly once the disk turned out to be Oneway's
crack of tape version 1: the crackers' loader names each stage's three
files by letter, and their `←` key gave a route through every stage.
Each stage was annotated from its own snapshot; stage 1 lives in the game
part's session.

Wrong turns, all corrected: the music driver's interleaved pointer tables
were first typed as split Lo/Hi tables, which invented labels inside the
data; the blue crystal's launcher was called unreachable because it is
reached only through the split weapon table; the beam's damage formula
and the game-over tune were misread. The sample (seed 1110, 80 comments)
found 9 more, including a driver variable misread in all nine copies of
the driver and 43 template labels that claimed references nothing makes.

The F7 key pauses in this copy, against the C64-Wiki's "F7 toggles the
music". A reference screenshot labelled stage 1 shows scenery that stage
1's map does not have; it was left out of the pages.

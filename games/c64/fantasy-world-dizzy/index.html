Secret: ESPILCE opens a room browser

During play, enter ESPILCE, releasing each key as you move to the next. The game compares seven keyboard codes at $3AE9. The successful path hides the sprites, restores two spare lives and enters a room browser at $3B23.

The input sequence was checked with real keyboard events. Execution stopped after each key changed, then instruction stepping followed the write of two to $03B9. The browser's navigation and room limits remain to be verified.

Evidence: $3B00–$3B58. The trace summary is recorded with the analysis.

A frame captured during play. Rebuilding the frame from its recorded memory and chip state matched all 104,448 pixels in VICE's picture.

The player is a hardware sprite. The room is a bitmap assembled by the drawing routine at $2B5B. The room decoder has parsed 101 drawing streams with 2,783 records. This is a count of stored drawing streams; it does not establish that the player can visit every one.

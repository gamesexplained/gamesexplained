About this page

The copy studied

The pages describe a disk image named C64.COM holding the program BOULDER DASH, a re-packaged copy with a BASIC stub and a copier in front of the game; its title screen reads “(C)1984 First Star Software Inc.” The game is one load, and the addresses on these pages are those after the copier has moved it to $5000-$8FFF. The Source tab's listing is built from memory saved a few seconds into cave A, level 1. No other release was compared. No game image is hosted here.

Original game credits

The game's menu screen shows two names: “BY PETER LIEPA” and “WITH CHRIS GREY”. The credits below come from the sources named beside them.

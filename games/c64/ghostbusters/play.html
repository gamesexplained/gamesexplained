01 · Start anywhere

A level select made of the game's own start

Ghostbusters has no levels, only a clock: the city's PK energy, which climbs until the Keymaster and the Gatekeeper meet. The start buttons take you to the points along it that are worth playing.

No saved snapshot is involved. The page starts the game from its first instruction and plays its start for you without drawing it: F1 on the title, VENKMAN,PETER at the interview, no account, the station wagon on the car page. In the shop it puts the equipment in the car as the shop would have left it, then presses E. That takes the game about 2,200 frames, around 45 seconds of C64 time, which the page runs in a fraction of a second.

02 · Cheats

Four cheats, each one variable or one routine

Each cheat can be switched on and off at any moment. Off, the game is the original again.

The port does not run the game's bytes, so the page makes its own money_subtract return at once, which is what the POKE does.

03 · The port

Every routine of the game, checked against the original at every pass

Nothing on this page emulates a 6502. The game's routines are written out in JavaScript, one function each, named by the listing's labels, and run on the game's own 64 KB of memory.

The page loads that memory from the listing, the same bytes the Source code tab shows. From then on the port reads and writes the game's variables where the game keeps them, with the game's own decimal arithmetic, its self-modified operands and its bugs: the two bytes each drive leaves on the stack, and the empty branch at $7200.

How it was checked

The original code runs in a 6502 simulator beside the port, from the same saved moment and with the same keys and joystick. At the start of every pass all 64 KB are compared, with colour RAM. Only the stack page is left out.

Where the original depends on its interrupts

The title's tune during speech. While a phrase plays on the title, the game steps the tune, the lyrics and the ball from a loop that compares the raster line with the last one it read. It reads the line's two parts one after the other, and the speech interrupt can fall between them, so the game sometimes steps twice in a frame: 98 steps in 88.7 frames for one phrase. The port steps once a frame, so on this page the sing-along can end a fraction of a second later.

The random number. The raster interrupt steps the random number $06 once a frame, at line 184. When a pass starts late, after a slow one, the main program reads $06 after the interrupt has stepped it. The port runs the interrupt between passes, so its read gets the value before. Three places read it this way: the Roamer's spot on the road at the start of a drive ($8113), the Keymaster's and the Gatekeeper's turns ($7DFF) and the new haunting ($740C). On this page a Slimer or a Roamer can therefore turn up somewhere the original, at that moment, would not have put it. Either is a place the original can choose.

The character set is built at start-up from the machine's character ROM: the code at $608A copies 1,016 bytes of the upper-case letters from $D008-$D3FF of the 901225-01 character ROM. The page carries those bytes, and nothing else of the ROM.

04 · Speed

It runs at the C64's speed, pass for pass

The game does one pass of its main loop a frame, and some passes take several: drawing the map, a building, Zuul's tower. A port that ran each pass in a frame would be too fast there.

So the page keeps a PAL machine's clock: 312 lines of 63 cycles, 50.12 frames a second, with the raster interrupts on their lines. The port does not execute instructions, so it cannot count their cycles. Each pass costs the median time the original's pass took in the same game state, measured on the simulator over 78,000 passes of the lockstep sessions, and the interrupts, the speech and the raster waits take their own time.

05 · Differences

What differs from a C64

  • The screen. The video chip is drawn line by line from the registers the game writes and the line each write lands on, which is how the game splits the screen into the picture, the status line and the scroller. A write lands at the start of its line.
  • Sprite collisions. On Zuul's street the Marshmallow Man catches a man when their sprites touch ($D01E). The page works the collisions out from the sprites' positions and shapes once a frame.
  • The sound. The game's writes to the sound chip go to the site's model of the SID, a frame at a time. The speech is the game's own: its five phrases decoded by the port of its speech player and played as samples, while the game waits for them as it does on the machine.
  • The interrupts. They run between the steps of a pass, not inside them (section 03).
  • The keyboard. The arrows are the joystick in port 1, the port Ghostbusters reads. The other keys are the C64's by name. Esc is RUN/STOP, and the button beside it holds RUN/STOP and presses RESTORE.

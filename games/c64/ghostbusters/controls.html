The joystick

The joystick goes in port 1

Most C64 games read the joystick in control port 2, which the keyboard does not share. Ghostbusters reads port 1 and nothing else, as its manual says.1

Port 1 shares its register with the keyboard's columns ($DC01), so a joystick move and a key press can be mistaken for each other. The game's own keyboard scan guards against that: it gives up while either port reads anything but "nothing pressed" ($96CA, $96E8), so pushing the stick never types a key.

The keys

Function keys to start, and space for a report

The keyboard starts the game, types the name and the account number, and in play gives a status report and a pause.

F3 is a shortcut for the next game. The flag that says a name has been typed ($6328) survives RUN/STOP and RESTORE and the cold start at the end of a game, so F3 skips the interview and starts with the account the last game printed.

01 · Checked against the guides

Where the code and the guides disagree

The manual, online guides and cheat lists make claims about the game that its code settles. Each of these was tested on the game's own code.

The claimWhat the code does
The manual: the game ends when PK energy reaches 9,999.Nothing happens at 9,999. The game ends when the Keymaster and the Gatekeeper meet at Zuul, which in simulator runs happened anywhere from 8,495 to 9,999 (The city).
Online guides: GOOD TRY is the ending for having enough money but not reaching Zuul.GOOD TRY is shown when the Marshmallow Man catches two men on Zuul's street ($8B10, The city).
Cheat lists: POKE 22014,9 gives unlimited lives.In the copy studied, 22014 ($55FE) is a character on the screen that the start-up clears and nothing reads.
Cheat lists: POKE 38454,96 makes everything free.True: it puts an RTS at the start of money_subtract ($9636), so cars, equipment and the Marshmallow Man's damage all cost nothing. The Play tab has it as a switch.

02 · Bugs

Four bugs, and what each one does

None of these stops the game. Three change what a player sees; one shows only in memory.

Bug: "more money than you started with" means "not less"

The meeting forecloses only when the balance is below the starting balance: the three-byte comparison lets an equal one through. A player who spends nothing and earns nothing goes on to Zuul, and at the end the game prints YOU MADE MORE MONEY THAN YOU STARTED WITH.

Bug: a blank name and 458 give a fortune that always loses

A blank name with account number 458 decodes to a top byte of hexadecimal $A0, which the game prints as ":" and calculates with as 100 (YOU HAVE $:00000). Spending money works, because the processor's decimal subtraction treats $A0 as 100. Earning it does not reach that far: money_add ($9664) stops at 99. At the meeting at Zuul the balance can never equal $A0, so the bank forecloses every time.

Bug: every drive leaves two bytes on the stack

State $14 reaches next_state with JSR ($8070) where every other handler jumps, and nothing takes the return address off again. The stack pointer sinks by two per drive. The stack wraps inside its page, and nothing the game keeps there is overwritten, so no player sees it.

Bug: ten traps read ":"

The status report (space in play) prints the number of empty traps as one character: the count plus the code for 0. The station wagon carries 11 items, so with at least $12,000 to spend it can hold 10 or 11 traps, and the report then says ":" or ";" (seen by setting the count).

03 · Left in the code

An item nobody can buy, and a building nobody visits

Some of the game's data and code can never be reached in play, and one rule can leave a building out of the game for good.

Secret: an eighth item with a price and no shelf

The price table (item_price, $A1DC) has eight entries. Item 4, sprite shape $37, costs $600 and sets no equipment flag. No shelf holds it (shelf_shapes, $AAB3), so it cannot be bought. Two items at $600, a trap and this one, may mean a second kind of trap was cut; the code does not say.

A building the Marshmallow Man forgets

The game keeps one Marshmallow building ($80). If PK energy crosses the next thousand before the alert, a new building is picked and the old one is left at state $F8. It never ages out of it: the stage table sends stage 2 back to $F8. That building is never haunted and never stomped for the rest of the game, and it shows white to a sensor near the logo. In the eight runs from 5,000 no alert came at all, because Roamers reaching Zuul pushed the meter up a thousand at a time.

04 · Open questions

What we have not settled

Everything above was traced in the code or seen when the game ran. These are the questions the code leaves open, or that nobody has checked yet.

  • What phrases 2, 3 and 4 say. Phrase 1 is "Ghostbusters!". Phrase 2 plays when a man is slimed and phrase 3 when a man is caught at Zuul, so "He slimed me!" and a laugh are likely, but no one has confirmed them by ear. Phrase 4, when the portal closes, is unknown. Phrase 0 is never played (Music and speech).
  • Whether item 4 was a second trap. Only its price and its sprite are left.
  • How often the Marshmallow alert comes in real play. In eight simulator runs from 5,000 PK energy it never did: Roamers reaching Zuul pushed the meter past each thousand first.
  • Whether the original releases match. Two copies have been compared and share every byte of the game's code (About). Neither is a publisher's original disk or tape.

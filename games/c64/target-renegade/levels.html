1988 · Imagine Software · Commodore 64

Target Renegade

Five stages, drawn from two maps and three sets of character shapes per load.

01 · Maps

The stage backgrounds

Each map is 80 columns wide and 20 rows tall. A map square holds a number that chooses a block of 4 × 4 characters. Each character chooses an 8 × 8 picture. That makes the whole stored background 2,560 × 640 pixels. The game shows a 320 × 160 window above the status panel.

Loading map data…

The full stored map appears below the window at half size. Scroll sideways to see its width. Changing stages also changes the character shapes and colours. Some stored areas lie outside a stage's usual route. The browser shows the stored data without claiming that every area is reachable in that stage.

The column renderer at $2A6C reads map indices from first-load $2DC0 or second-load $2DC0. It selects sixteen character codes from the tile table at $B000. Resource swaps at $84FE put the chosen character shapes and colours into the memory areas the display reads. These addresses identify where the game keeps each table.

The map lookup was checked against the game's own renderer for 51,200 character cells across both loads. The five font/colour selections were also compared with initialized native stage snapshots. The window omits fighters and the status panel.

About this page

The copy studied

The pages describe a disk release of the game, as a G64 image. The disk holds two files. JR, 246 bytes, is a BASIC line that loads over the stack page, so the KERNAL's LOAD returns into it; it loads JUMPMAN JR., 16,431 bytes, into $8000 to $C02E. That file is the 16 KB cartridge image, with the cartridge's CBM80 signature at $8004, followed by 47 bytes at $C000 that copy the KERNAL ROM into the RAM under it and switch that copy in. One byte of the copy is patched, the value the KERNAL's IOINIT writes to $01, so that the game's own call of IOINIT leaves its code at $A000 in place of BASIC's ROM.

The image on the disk is not the whole cartridge. Its first 268 bytes of code, from $8009, are a protection: a stub decrypts a second stage, which sends a program to the disk drive, reads the copy-protected track through it, and puts the cartridge's real first bytes back before starting the cartridge's own start-up. The protection is not described further on these pages.

The listing on the Source tab is built from memory saved a few seconds into level 1. Whether the disk is Epyx's own or a later conversion is not known from the image. The cartridge itself was not compared.

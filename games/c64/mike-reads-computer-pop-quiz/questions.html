01 · The subject questions

1,275 questions in five blocks

The cassette holds five question blocks, and a game loads one of them. Each block has 255 questions on the six specialist subjects, 42 or 43 to a subject, each with one right answer; the three wrong answers the game shows beside it come from other questions. Choose a block and a subject, or search.

Built by running the game's own code on the kit's 6502: the question builder at $3416 and the answer writer at $3C3A, once for every question number of each block, from a snapshot of the game with that block loaded. The text is the game's. Its font draws the codes for ( and ) as opening and closing quotation marks, shown so here, and the game puts a space inside each and before the question mark, which this list closes up.

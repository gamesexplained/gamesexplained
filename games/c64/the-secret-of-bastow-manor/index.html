A whole adventure in one BASIC program with no machine code in it. The program switches off BASIC’s own LIST command, and its safe’s combination is never written down in one place.

Getting into the manor

You stand on the misty moors outside the walls of Bastow Manor, and old man Bastow has disappeared. The game gives you a typed prompt and a small picture of each of its twenty-seven places, drawn with the Commodore 64’s own graphics characters. You type one or two words, such as get key or open gate, and the game answers in a line or two.

The game begins at the manor’s gates, which are locked. Opening them lets the dogs loose, and from then on every move spent in the open counts against you. The way in is a chain of small puzzles that the Gameplay page lays out in order: a branch from a dead tree, a key from a mailbox, a torch for the dark places, a pit of snakes, and a locked chest guarded by a robot.

You win by taking the gold out of the treasure room and leaving through the gates before a skeleton catches you. Carelessness ends the game with a tombstone and the question whether you want to try again.

The people behind the game

The game was written by Darryl Reynolds in 1983 for the VIC-20 and the Commodore 64.1 The Solution Archive spells the name “Darryll D. Reynolds” and lists SoftGold as the publisher, with Dotsoft and Gameworx named beside it.2 It also records that the title comes from a local street, and that the VIC-20 version has shorter descriptions, fewer objects, and no graphics.

The game shows no name beyond the year 1983 on its title screen. The disk studied here is a cracker’s transfer rather than the publisher’s own, and no second copy was available to compare it with.

The C64 version is formally titled “The Secret of Bastow Manor 64” and is written in BASIC, which the program bears out: its Source tab is 953 numbered lines.1

What players made of it

No review of the Commodore 64 version was found. The Computer and Video Games index for March 1984 that a search returned has none in the part that was read.5 The Solution Archive’s only rating, 6.5 from two votes, names no platform, so it is left out here.2 What survives from players is two published walkthroughs, one of them written for the C64 version.34 Replaying that one command by command in an emulator, the game took every command it gave.

What is hidden in the program

Line 17 of the program switches off the LIST command, so a player who stops the game and tries to read its listing gets only a line number. The chest’s four-letter combination is assembled from letters set in four different places, and the game can be won without ever picking up the gold. Two blocks of the program are never reached, and the title tune’s last note is read but never played.

Follow the puzzles in order, see every place, or hear the title tune.

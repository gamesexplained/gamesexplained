A whole adventure in one BASIC program that switches off BASIC’s own LIST command, so the game cannot be read where it stands.

A game that will not let you read it

Stop The Secret of Bastow Manor and type LIST, and the Commodore 64 prints a line number and nothing else. Line 17 of the program pokes one byte into the vector BASIC’s LIST command goes through. The whole adventure is a BASIC program with no machine code in it. The Discoveries page shows it working.

Behind the lock is a text adventure. You stand on the misty moors outside the walls of Bastow Manor, and old man Bastow has disappeared. You type one or two words, such as get key or open gate, and the game answers with a line or two and a small picture of each of its twenty-seven places, drawn with the Commodore 64’s own graphics characters.

The gates are locked, and opening them lets the dogs loose. The way in is a chain of small puzzles: a branch from a dead tree, a key from a mailbox, a torch for the dark places, a pit of snakes, and a locked chest guarded by a robot. You win by taking the gold out through the gates before a skeleton catches you, and carelessness ends the game at a tombstone.

The people behind the game

The game was written by Darryl Reynolds in 1983 for the VIC-20 and the Commodore 64.1 The Solution Archive spells the name “Darryll D. Reynolds” and lists SoftGold as the publisher, with Dotsoft and Gameworx named beside it.2 The same page also records that the title comes from a local street, and that the VIC-20 version has shorter descriptions, fewer objects, and no graphics.

The game shows no name beyond the year 1983 on its title screen. The disk studied here is a cracker’s transfer rather than the publisher’s own, and no second copy was available to compare it with.

The C64 version is formally titled “The Secret of Bastow Manor 64” and is written in BASIC, which the program bears out: its Source tab is 953 numbered lines.1

What players made of it

No review of the Commodore 64 version was found; what survives is two published walkthroughs.

What else is hidden in the program

The chest’s four-letter combination is assembled from letters set in four different places, and the game can be won without ever picking up the gold. Two blocks of the program are never reached, and the title tune’s last note is read but never played.

Follow the puzzles in order, see every place, or hear the title tune.

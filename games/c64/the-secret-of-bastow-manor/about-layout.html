About this page

The copy studied

The pages describe a cracker’s disk transfer named ASS PRESENTS:, which holds the game’s one BASIC program and two saved games. No second copy, and so no publisher’s own disk, was available to compare it with. The game is a single load, and the addresses on these pages are those of the program as BASIC holds it after LOAD, before RUN. No game image is hosted here.

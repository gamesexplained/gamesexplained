Commodore 64 · 1991 · Ocean Software

Toki

The background maps of all five stages, drawn from the game's own tables.

The maps

Every stage is one grid of 16-pixel blocks

Each stage's background is a single map, and the game scrolls a window over it.

A stage's map is a table of rows with one byte for each block $002A. A block is two characters wide and two high, 16 pixels square, and the byte is a block number that picks four characters from a table $0D32. Each block also has a properties byte that the movement code reads: bit 0 means solid, bit 1 harmful, and bits 2 and 3 slopes $197E. The first three blocks are blank. In stage 1 the table holds 91 blocks.

The stages differ most in shape. Stage 2 is a long corridor 155 blocks wide and 34 high, and stage 3 is a tall shaft 87 blocks high. The size comes from the row address table and the gap between its first two rows in each stage's snapshot.

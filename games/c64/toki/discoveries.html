Commodore 64 · 1991 · Ocean Software

Toki

What the code does that the manual does not say.

Secret: a stage skip behind two joysticks

The player routine tests for up and fire on joystick port 2 together with down and fire on port 1 $8572. Every frame the pair is held, the game adds one to a cheat flag and one to the background colour. With the flag set, the Commodore key skips to the next stage while the stage number is below 4. In VICE on 25 October 2026, holding the pair from the first stage raised the flag by one a frame, and the Commodore key then moved the game from stage 1 to stage 2. The Commodore key on its own did nothing. The skip from later stages was not tried.

Three tune sets, one named by the main code

The sound driver holds three sets of voice scripts $70BA, and the main code starts only the second. The Music tab says what is known about the callers.

Code nothing runs

Four jumps into the scroll routines have nothing that jumps to them: $4A04, $4A68, $4AC7, and $4B3E. The one-shot sound data also has two stretches that no sound record reaches $6FFD. They look like leftovers, but nothing in the code says why they are there.

What the code does not settle

Which arcade level the C64 version leaves out is not found. The bar beside STAGE is not explained: it shows the health of the stage's goal object only while a flag is set, and nothing in the code that was followed sets that flag $08CB. The cartridge banks hold sprite shapes and object definitions whose origin was checked only against a contributor's older notes.

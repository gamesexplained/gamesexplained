A joystick in either port flies the Manta; a handful of function keys set the game up, and RUN/STOP pauses it. There is no keyboard control of the ship.

01 · Flying the Manta

One joystick, in either port

The ship is flown with a single joystick. The game reads both ports and acts on either (read_stick, $B019), so it does not matter which one the stick is in — unless two players each have their own, which the F3 option sets up below. Up and down change the Manta's height; left and right are its throttle, not its steering.

InputWhat it does
Up / downClimb and dive. The stick nudges the vertical velocity one step a frame up to the level's limit; centred, the velocity halves back towards level each frame (manta_vertical, $2576). Vertical position is $16.
Left / rightAccelerate backwards and forwards. Left and right do not turn the ship; they add to its signed speed, so the Manta speeds up, slows, stops and reverses along the hull (manta_speed, $2635). Horizontal is $17.
FireFire a pair of shots at once, one from each gun, on the press, and a second pair on the release (manta_fire, $2959; fire_control, $292F). Fire is $18, zero while the button is held.
Hold fire,
then up or down		Flip the ship. Once fire has been held for seven frames ($49 counts down from 7 to 0), the next push of up or down rolls the Manta edge-on and through a half-loop to face the other way, so it can turn round and strafe back — as long as it is moving at speed 3 or more and not already in a manoeuvre (manta_vertical; the turn's own acceleration carries it through, manta_speed).

The Manta never collides through the video chip's sprite registers. Every hit — against the hull, a wall, a shot — is worked out from the map characters beneath it (manta_collide, $27D5; How it works).

02 · Starting a game

Fire starts the game from any title screen

The outer loop cycles through four attract screens — the title page with the music, the giant scrolling message, the hall of fame, and a demonstration flight. Pressing fire on any of them starts a game (title, $0A20; new_game). A game begins on level 1, the Zinc Dreadnought, with three lives.

03 · The title keys

Function keys set the game up before you start

The function keys are read only on the title screens, into a bitfield (read_keys, $B1FD). Each of F1, F3, F5 and F7 pairs with its SHIFTed form (F2, F4, F6, F8). Each option shows a small icon in the status line.

KeyEffect
F1One player ($5C = 1) (option_keys, $2342).
F2 (SHIFT + F1)Two players sharing one joystick ($5C = 2); the turn passes when a life is lost.
F3Two players with a joystick each ($5C = 0). This is the one setting that reads the two ports separately.
F5 / F6Turn the music volume up (F5) and down (F6), 0 to 15, five at the start (volume_keys, $B31B). The reading is shown as Volume nn.
F7 / F8Colour (F7) or black and white (F8) (colour_keys, $23B5). Black and white makes every Dreadnought use the plain scheme instead of its own colours.

04 · Pausing and quitting

RUN/STOP pauses; CLR/HOME abandons the game

In play, only three keys are read, and they are read apart from the joystick (read_pause_keys, $2F9D; pause_check, $2B6D).

KeyEffect
RUN/STOPPause. The word Pause appears in the status line and the sound stops. Press fire, or RUN/STOP again, to carry on; the frame counter is kept so nothing is lost.
CLR/HOME (while paused)Abandon the game in progress and go back to the title screens.

RUN/STOP sits in the same keyboard column the joystick's right direction would read, so read_pause_keys ignores it when port 1 is being pushed right, to keep a strafe from pausing the game by accident.

01 · Differences

What differs from a C64

The game plays as it does on a C64, at the C64's pace. These are the places where the page cannot be the machine, and what it does instead.

On a C64On this page
The tape's turbo loader reads the game into memory and starts it at $4000.There is no loading. The page starts at $4000 with the memory as the loader leaves it, and the title tune and the control menu come up at once.
A save writes the game's state, the 1,535 bytes from $CA00 to $CFFE, to tape or disk through the KERNAL, and a load reads it back. On tape the game asks for PLAY (and RECORD) to be pressed.The page has no KERNAL. It keeps the same bytes in this browser under the name typed, for tape and disk alike, and a save or a load takes the game's own pause and no more. The cassette's buttons are always down, so the tape's prompt shows for a moment. A name the browser has no file for gets the game's own FILE NOT FOUND, as the KERNAL's error 4 does.
The interrupt can fall between any two instructions of the main program.The interrupt runs between two of the port's steps, at the clock's time for it. A byte the interrupt changes and the main program reads in the middle of a routine (fire, the clock, a team member's place, the mission) is read once the interrupts due by then have run, so the game's races come out the way the clock says rather than the way the beam would.
Each instruction takes its cycles, and the video chip takes some of the processor's on the lines where it fetches characters and sprites.The port executes no instructions. Each routine and each picture byte, glyph and search step costs what it costs the game, and the video chip takes its cycles as the beam passes those lines, so a screen draws and the iris opens at about the C64's pace.
The SID plays the music and the effects.The game's own music driver runs on the site's 6502 in the port, as the How it works page's tune player runs it, and the site's model of the SID, with the filter of the C64's original 6581, plays what it writes as each frame is shown.
The video chip draws the screen.The site's model of the video chip draws each frame from the port's memory, with each change the port makes during the frame applied where the beam meets it.
The game reads its joystick in port 1, whose lines it shares with the keyboard's, so some keys move the stick: Space is fire.The arrows and Space are the joystick in port 1, and the other keys are the C64's keys of the same names.
A light pen reads where the beam is as it passes the pen on a television's glass, and an analog joystick, or a pair of paddles, sets a voltage the SID measures.The mouse is both. The page gives the video chip's light pen registers the beam's place under the mouse, and the SID's two pot inputs the values that put the cursor under it, and a click is the button.
RUN/STOP held with RESTORE starts the game again from its control menu.The RUN/STOP + RESTORE button presses both at once.

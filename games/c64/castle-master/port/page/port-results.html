The game is a 6502 program of about 28,000 bytes of code. The port is the same program written again in JavaScript, one function for each routine the game calls, 123 in all, reading and writing the game's variables at the game's own addresses. The page runs only the port.

The music is the game's own driver, which the page runs on a model of the 6502.

The information screen's save, to tape or disk, writes the same file the game writes, and a load puts back the same game; a file that is not a saved game prints INVALID FILE, as in the game.

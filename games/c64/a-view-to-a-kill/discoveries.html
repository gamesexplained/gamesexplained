Where the code and the sources disagree

02 · City Hall

Bug: a burning room runs the end test from the middle of an instruction

The main loop's test for a burning room branches to $7090, which is the second byte of a branch instruction. From there the processor reads ORA $57AD, then an undocumented instruction that shifts a byte of memory left and ORs it in (SLO, writing $0BFC), and arrives at the load of the code flag in the end test ($7096). Seen in the emulator with Bond's room set on fire: with CCPHJ typed, the next pass ended in the mission-complete screen with DB4CT; without it, a new game. Whether the branch was meant to go to the end test and the target is off by a byte, or was changed later, is not known.

Energy and the clock cannot kill Bond

The energy objects set a value for Bond and one for Stacey that nothing reads or draws ($1B5B, $1B5C). The clock counts and nothing reads it: where a test might have been there are nine NOPs ($6EA1).

Room 38 holds furniture with no place

Room 38's record names a second piece of furniture, type $A1, at address 0 ($A20E, copied to $443E). In the emulator Bond went through the door from room 39, the room was drawn and play went on; what the drawing routine makes of a type that high was not worked out.

A table read from the screen

When the fire spreads to the next floor, the new temperatures are masked with AND $03E9,Y ($95AD), a read of the screen, where an AND # of a fixed value was probably meant. Not tried in the emulator.

03 · The intro

Bug: the credits depend on where the raster beam is

Before the credits the intro writes $97 to the video chip's control register ($CB50). Its top bit is also the top bit of the raster line the next interrupt is asked for, which becomes line 496, a line a European screen never reaches. A later read, AND and write of the register clears it ($C540), but reading that bit gives the line the beam is on, so if the beam were below line 255 at that moment the bit would be written back set. Then no interrupt would ever come again, and the credits, the music and everything else driven from the interrupt would stop. In four boots in the emulator, started a tenth of a second apart, the beam was on lines 25 to 29 each time and the credits scrolled; whether the stall can happen at all on this disk is not known.

04 · Paris

Bug: the locator is cut off by one byte

The cockpit's locator lamp should flash, and a beep sound, faster the closer the car is to May Day ($4A50). The interrupt's sound routine calls it at its end, but a return instruction sits on the first byte of that call ($51E9), where the load of the sound option should begin. Nothing else calls it, so the lamp never lights and the beep never sounds. In 30 seconds of a chase in the emulator, with the effects on, it was not called once.

05 · The mine

A digit counter with no limit

Each digit entered is stored at $1B73 plus the count so far, and nothing limits the count ($38AA). The numbered objects stay in the list after use, so a digit can be entered again and again. The fourteenth digit would land on the pause flag and stop the clock, and the forty-sixth on the code flag itself, which would make the section winnable without DB4CT once the count wraps round after 256. None of this was tried in the emulator.

Two smaller slips: the welcome page loads the stack pointer from the byte at $FF where the number $FF was meant ($7D1D), harmless because the next routine sets it again; and the planks' handler tests for an object number no object has ($3970).

06 · Left in the files

An older code, an older end screen, and a word left in three places

City Hall holds a code prompt nothing calls, which asks for QRS21 and gives three tries ($967B), and an end screen nothing shows: WEBL DONE 007 YOUR CODE IS 111122 ($7E5A). It also holds most of the mine's end text, with ILVCT, among the bytes its loader left behind.

The word ZOOM ends a page of memory in three programs: in the intro as "MOZOOM1000" ($9FF6), in City Hall inside the icon of item 52 ($48FC), and in the mine as four tiles of the map, at row 54 ($9FFC), where the game draws them as four stray tiles. What wrote it is not known.

07 · Open questions

Questions still open

  • Which release the cracked copy came from: it plays differently in four of the five programs (About).
  • Why the small ovals on the Paris map do not sit on May Day's landing points (Maps).
  • What the meter on the mine's panel measures. It rises towards the upper right of the mine ($3000); the sources call something a Geiger counter.
  • Which of the two tunes is the Bond theme and which the title song.
  • What City Hall's door codes 1, 2, 3, 5 and 7 look like: the drawing code handles only 0 and 6.
  • Why Paris rewrites two short stretches of its map at every start ($4140).

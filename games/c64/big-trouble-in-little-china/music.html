02 · How it plays

One strike, three voices, slightly out of tune

An effect is six bytes from six tables ($2B06-$2B35): pulse width, frequency, waveform and attack and decay. sound_update writes the same effect into all three voices, raising each voice's pitch a little more than the last, so the three beat against each other.

The game asks for an effect only in the loop where something happens, and clears the request at the start of every loop (game_frame, $117F). An effect is therefore one strike of the gate, with no sustain, that fades on its own decay. The jingle, played at the start and when the prize is taken, is effect 3 struck 29 times with a wait between strikes, the processor doing nothing else meanwhile (jingle, $2B44).

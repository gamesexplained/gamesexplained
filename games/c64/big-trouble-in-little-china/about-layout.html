About this page

The copy studied

The pages describe a cracked copy on disk, one packed program that puts back a frozen machine and starts at the title ($11FE). The game's own loader and start-up code are not on that disk, so nothing here describes them. The game is one load: everything it uses is in memory from the title on, and the addresses on these pages are those of that memory. The Source tab's listing is built from memory saved a few seconds into play.

No game image is hosted here.

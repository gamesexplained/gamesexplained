Extra fuse settings hidden in an ordinary keyboard read.

Secret: grenade keys combine into fifteen fuse settings

The instructions offer four throwing distances. Holding several grenade keys at once gives more choices. Each key contributes a value, and the game uses their sum as the fuse.

One engine pass is one update of the game world. One grenade is spent for a launch, even when several keys are held. The first pass launches it; the fuse then counts down. Collision can stop its flight before the fuse ends.

The keyboard read at $8D00 keeps all four key bits. S contributes 2, D 4, F 8, and G 16. The fifteen nonempty combinations therefore give every even fuse value from 2 through 30.

In a recorded gate-area test, S alone exploded on engine pass 3. S+D+F+G exploded on pass 31. Both spent one grenade. The same 36-pass inputs reproduced every recorded position, fuse, ammunition, and explosion value on ZEsarUX and the independent Spectrum machine.

A longer fuse can leave a grenade caught against a wall. It also delays the point when you can throw another. This changes timing as well as range.

What the test establishes

The recordings begin at the first rescue’s gate-area snapshot and use keyboard input throughout. They establish that the combined fuse is reachable in normal play. They do not establish a route through every rescue or guarantee a safe throw.

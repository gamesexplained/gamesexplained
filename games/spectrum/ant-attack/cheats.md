# Ant Attack — cheats and useful inputs

## Extra fuse settings

Hold multiple S/D/F/G keys together when launching. Their values
2/4/8/16 add into the fuse. All four produce 30, spending one grenade.
The Discoveries tab shows all fifteen nonempty combinations. This was
replayed with keyboard input on two machines.

## Retry

`1` returns from the machine-code engine to BASIC's retry sequence.
The original instructions describe it as the last resort to return to
the gate. It is not an unlimited-ammunition or invulnerability cheat.

No memory-poke cheat is recommended by this run. Controlled state changes
used for verification are documented as tests in facts.md.

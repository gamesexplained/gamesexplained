A city built from six-bit columns, with four views of the same danger.

The game

Choose the boy or the girl, enter the city of Antescher, and find the other person. Bring both people outside the city before the timer runs out. Ten successful rescues earn a medal.

Ants occupy the same streets and climb the same blocks. A jump can save you from a bite. Grenades clear space, but can kill either person.

A city stored as vertical columns

A single map holds every rescue. Each square contains six yes-or-no answers: is there a block at this height? Gaps let a column hold an overhang as well as a solid wall.

In Plan view, click a column to read its six occupancy bits.

The red marker is a rescue location from the BASIC program. The first rescue has one location; each later rescue has four possibilities. The city occupies 16,384 bytes at $C000. The block test at $8920 chooses a height bit; $8380 reads the columns for the camera.

The Map tab lists every rescue location. This viewer uses solid faces to expose the columns; the original renderer uses dithered wall blocks.

Beeps become a score

The title flashes while BASIC repeats two pitches, then plays a rising scale. During play, the machine-code messages carry sound commands alongside their text. The medal has its own long sequence.

Title and timeout: ROM BEEP port writes captured in ZEsarUX. Effects: the game’s own routines run on the kit’s Spectrum machine. The shared Spectrum sound model plays those timed speaker changes. The title has 3,128 edges; the two machines agree within six processor cycles per edge interval. The final rising notes exceed the emulator WAV’s useful bandwidth, so the port-write timing is the reference.

Messages are interpreted at $8E0D. Tone delay/duration pairs begin at $8BB1; $8B4A supplies noise. BASIC title lines start at $77DA and $78B1.

Walking, climbing, and following

A direction chooses one of four neighbouring squares. The movement routine tests the next square at the actor’s height. Jumping tests the square above; holding forward and jump together lets you climb.

The other person begins following when the horizontal distance is below four and both people have the same height. Horizontal distance adds the two coordinate differences, so diagonally offset squares count twice. The scanner changes colour according to whether that distance decreased.

The recognition test is at $8F80; following movement is at $8AB6. Graphics shows the moving shapes and their masks.

Remaining time earns more on later rescues

Each successful rescue adds remaining time multiplied by the new rescued count. The total carries into the next rescue. Ten rescues finish the game.

BASIC line 90 at $5E49 does the calculation. The timer at $8DD0 counts engine work, with one decrement every third update. A busy view can take longer to draw, so a timer unit should not be read as a second.

The play screen rebuilt from video memory

All 49,152 active pixels match the emulator by colour number. The shared renderer uses a brighter normal palette: intensity 215 instead of ZEsarUX’s 192. The panel and picture come from 6,912 display bytes captured in play.

The engine draws into a linear buffer, then $8100 copies the view into the Spectrum’s unusual scanline order. $8500 merges walls and actors by depth so a person can disappear behind a wall.

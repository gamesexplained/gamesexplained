The game is a Z80 program of about 20,000 bytes of code. The port is the same program written again in JavaScript, one function for each of the game's 89 routines, reading and writing the game's variables at the game's own addresses. The page runs only the port.

Collecting a rig in Amethyst before any rig of the game has been put down reads the gas from a table whose pointer is still 0: the ROM's first byte, $F3. The page carries that one byte of the 48K ROM and nothing else of it.

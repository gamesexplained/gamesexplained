The game is a Z80 program of 22,521 bytes, the engine, and five scenarios of 18,911 bytes each, loaded from tape over the top of memory, each with routines of its own and its own copy of the computer player. The port is the same program written again in JavaScript: one function for each of the engine's 289 routines and for the 40 routines the scenarios carry, in 144 copies, each reading and writing the game's variables at the game's own addresses. The page runs only the port.

The game's dice add the Z80's refresh register, a byte read from a pointer that walks the whole of memory, and the time spent waiting for keys. No port can keep the refresh register, so on this page it is noise.

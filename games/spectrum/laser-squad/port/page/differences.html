The game plays as it does on a 48K Spectrum, at the 48K's pace. These are the places where the page cannot be the machine, and what it does instead.

On a SpectrumOn this page
Each instruction takes its T-states, and a turn of the computer's takes as long as its thinking does.The port executes no instructions. Each stretch of the program between two reads of the controls, each routine it calls and each piece of work inside them (a view drawn, a line of sight walked, a word printed) costs what it cost the game, fitted on the game's own timings (The pace, under How the port was checked), so a turn takes about as long as on the Spectrum.
The random numbers add the refresh register, which counts every instruction the processor fetches, to a byte from a pointer that walks through the whole of memory: the ROM, the game's code, the stack.No port can keep the refresh register, so it is noise, between 0 and 127. The page does not carry the ROM or the game's code, so a byte the walk reads there is noise too. The shots, the morale tests and the computer's choices are drawn the way the game draws them, from numbers just as unpredictable.
The menus read the keyboard through the ROM's KEY-SCAN routine.The port reads the keys the way KEY-SCAN does, and charges the time it took the game.
The ULA draws the screen a line at a time as the beam crosses it.The page takes the screen whole at the moment the beam would reach its first line, so a change made while the beam is drawing shows a frame later, all at once.
The beeper is toggled from the effects' timing loops, with the game stopped while each plays.The site's model of the beeper plays the port's writes to it, each at the T-state the game's loops give it, and the game waits for the effect as it does on the Spectrum.
Choosing a scenario plays its block of 18,913 bytes from the cassette at the ROM's speed, which takes nearly two minutes.The page carries the five scenarios' blocks, and a scenario loads at once.
Save Game, in the menu between turns, saves the game to tape; Load Saved Game, at the first menu, loads it back.A saved game is kept in the browser, and offered as a .tap file to download. Load Saved Game loads the one kept, or a .tap file given to the page.
The controls are the keys, a Kempston joystick, a Sinclair stick or the cursor keys, as the first menus choose.The arrow keys, and the pad under the screen, are whichever the menus chose, with Space, Enter or Ctrl for fire; every other key is the Spectrum's own.

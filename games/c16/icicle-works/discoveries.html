Icicle Works

Measured timing quirks and a name-entry limit that differs from the leaflet.

01 · Countdown timing

Secret: a countdown second lasts 51 frames

The PAL game loads 50 into its countdown divider. Later calls subtract one and return. A call that finds zero reloads 50 and changes the displayed time. That zero call makes the gap 51 interrupts long.

120

The rule is $6AFB. Four consecutive emulator measurements each counted exactly 51 IRQ-handler hits between subtraction events. This widget is checked against the original routine over divider and BCD-time boundary cases.

The clock therefore gives a little more time than a clock that changes once per fifty interrupts. The PAL machine itself produces about 49.86 interrupts per real second. Pausing with H stops the countdown.

02 · A difference from the leaflet

Secret: the score table accepts five letters

The original leaflet promises three letters for a high-score name. The program accepts five capital letters or spaces. DELETE removes a letter, and RETURN confirms the name.

The limit is the comparison with 5 at $8E21. The name-input rule is tested against the original code for all 256 input-byte values and editing sequences.

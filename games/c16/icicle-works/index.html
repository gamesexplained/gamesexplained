1985 · Commodore · Plus/4, 64 KB

Icicle Works

Falling parcels build Santa’s toys. Changing tiny picture blocks makes the factory move.

01 · Santa’s factory

The game

An avalanche has buried Santa's presents in snow. Santa digs passages to find the parts of a toy. Each collected part adds a piece to the picture at the lower right. A finished toy opens the doors to other rooms.

Snowballs and parcels fall into cleared passages. They can crush Santa, but they also let him deal with the factory's penguins and polar bears. The clock makes each trip urgent.

02 · Collecting and leaving

Presents build a picture

The first room needs three parcels to build its toy car. Each pickup reveals a particular piece, rather than filling the picture from left to right.

0 / 3

The game stores the piece order at $8F51 and $9051. Numbers beginning with $ are hexadecimal memory addresses: locations where the computer stores instructions or data. The room and toy data match the original code that loads a room.

After the toy is complete, leftover parcels become bonuses worth 20 points. Santa can use a door by holding fire and moving toward it. The Maps tab shows all sixteen rooms, their starting times, and their exits.

03 · Two sound voices

Music: a tune for work and a tune for waiting

The original music code at $8170 and $81E1 produced these recordings. The code was called once per display frame in the PAL version, made for the PAL television standard. It controls the sound through registers, small numbered settings in the sound chip. All 1,304 game-tune register writes and 759 title-tune writes match independent plus4emu captures in value and order. A model of TED, the Plus/4’s picture and sound chip, turns these settings into sound. Within each frame, the recording times the writes by processor instruction cycles. This timing omits the extra delays while TED reads memory.

TED, the Plus/4's picture and sound chip, has two sound voices that can play separate notes. The music gives each voice its own notes and lengths. A small volume change softens each note. The title tune also plays at the high-score table.

The melodies' names remain unidentified. The recorded note data and players are complete.

04 · Interrupting the tune

Sound: the music makes room for an effect

The original code produces the collection, completion, death, and crushed-enemy examples. During play, TED's timer changes the noise pitch. These short recordings hold that timer input at zero. The code at $6C68, $6E32, and $704C supplies the starting sound settings.

An effect borrows the second voice. With music enabled, the game saves its sound settings and pauses the notes for the effect. The game restores those settings after the effect ends, provided the life has not ended. A completed toy gets a higher collection tone and a brief flash.

05 · A spreading hazard

Water chooses one opening

Water grows into the first suitable neighbour in this order: left, right, down, then up. A timing test can make a call do nothing. The widget shows one call to that rule.

Click a neighbouring tile to change its kind.

A value below 32 permits a spread attempt.

The water code at $70F9 accepts empty space, snow, bears, and penguins. This model agrees with the original code on 4,096 combinations of timing values and tile kinds. The widget runs one water update by itself. During play, the game also moves the creatures.

Magic grids make a different bargain: a stationary snowball directly above a grid becomes a falling parcel below it, provided the square below is empty. Penguins can also produce parcels when crushed. Rooms with few loose parcels rely on these other sources.

06 · Drawing the room

A window follows Santa

This 320 × 200 picture matches all 64,000 pixels of the emulator's display window. The game was stopped during capture to keep the comparison still. The picture is drawn from the captured screen bytes and character set, the collection of tiny shapes used for drawing. The page contains those display data; the game program stays in the contributor's own copy.

The whole room is 38 tiles wide and 27 tiles high. Each tile is made from four characters. The game builds a large character picture in memory, then copies a narrow window to the visible screen. Changing the window's starting address makes the room scroll.

The camera code at $68E1 copies a window 24 characters across and 25 rows down. TED's shorter display window cuts off the top and bottom. The Graphics tab shows the changing characters that make the objects move.

07 · Controls

Dig beside Santa

Moving into snow clears a passage. Holding SPACE or fire with a direction clears or collects the adjacent square while Santa stays put. That lets Santa work beside a hazard.

Choose a control to see the direction returned by the game.

The control code at $6D42 was checked with both keyboard and joystick inputs in plus4emu. Each check began from the same stopped state. The joystick uses port 2.

The title's C chooses keyboard or joystick, M changes music during play, and P chooses one or two players. The Discoveries tab shows the countdown's timing and the name-entry limit.

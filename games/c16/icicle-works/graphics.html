1985 · Commodore · Plus/4, 64 KB

Icicle Works

The moving shapes, toy pictures, and character blocks that make the screen.

01 · Animation viewer

The factory’s moving characters

These viewers show all fifty stored animation frames. Each frame takes 32 bytes and consists of four eight-byte characters, tiny picture blocks. The PAL version changes them once every four display interrupts, regular calls to the game's timing code. That is about 12.5 changes a second. The lists at $6A97 through $6AFA select each frame and direction. Numbers beginning with $ are hexadecimal addresses, locations in the computer's memory.

02 · Room building blocks

The fixed tiles

Each fixed tile uses four characters stored next to each other, selected by the list at $744F. TED, the Plus/4's picture and sound chip, draws them with background colour $56. The other colours shared by the tiles are $22 and $06. Each screen cell also supplies colour $71.

03 · Toy gallery

The finished toy pictures

The pictures use all 163 pieces stored at $9171 through $A5D0. Each room has its own collection order. The room browser lets the picture build one pickup at a time.

04 · The display font

Characters build the whole screen

These 181 glyphs, or character shapes, begin at $7498. They are the small blocks used to construct the screen. The game copies them into its drawing font. Animation and toy assembly later replace some of those copies.

TED draws the screen as a grid of characters. The game changes a character's shape in memory, and every cell using that character changes with it. That makes water ripple and bonus tiles turn without rewriting the whole room.

Stored text uses the usual byte values for capital letters. The drawing font assigns different numbers to those letters' shapes. The text code at $88E7 adds $4F to a capital's stored value. That makes A use shape $90. Spaces use shape zero.

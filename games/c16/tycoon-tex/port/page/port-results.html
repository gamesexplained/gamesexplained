The game is a 6502 program of 6,645 bytes of code. The port is the same program written again in JavaScript, one function for each of the 105 routines the listing names, reading and writing the game's variables at the game's own addresses, its self-modified instructions included. The page runs only the port: the game's code is in the tests, as the original the port is held to.

CheckWhat it showed
Each routine aloneSeven test files call 97 of the port's functions and the game's own routines on the kit's 6502 simulator from the same state, 170,329 cases in all, and compare every byte of memory each one leaves, its writes to TED in order, and the registers it hands back. The states are 132 moments of play saved from ten games, on the menu, in the high-score table and on levels 1 to 10, with the registers, variables and controls changed at random. The other eight, the main loop, the menu, and the routines that start and end a game and a level, run in the lockstep.
The whole game in lockstepThe port runs beside the game's own code on the kit's Commodore 16, from the game's first instruction, and the two memories are compared at the start of every pass of the main loop. Four sessions of 40,000 frames each, about 13 minutes of play apiece, made 29,796 passes with every byte the same at each one, and every one of the game's routines ran in each. A scripted player drives both: on the menu it changes the difficulty, the lives and the sound, switches between the joystick and the keyboard, watches the demo, and types a name for the high scores; in play it moves the stick, or the keys, at random, shoots, pauses and carries on. In some games levels are finished, up to level 10, or the pressure is left to run out, or the score is set high enough for the table, or one of Plus/4 World's pokes keeps Tex alive or his lives unlimited; one game is left with ESC.
The interrupt's bytesThe game's main program reads 17 bytes that the interrupt writes, among them the controls, the random numbers and the flags for a death, a pause and a finished level. Where the C16 could take the interrupt between two of those reads, the lockstep gave the port the values the game read, so the check holds the port's logic and not the moment an interrupt happened to come.
The paceThe port executes no instructions, so the page charges each stretch of the main program and of the interrupt, and each call it makes, the cycles they cost the game, fitted on the kit's C16's timings of two sessions of 16,000 frames, some 354,000 stretches. On a third session, which the fit never saw, the page's cycles for its stretches are 0.9 % from the game's. The page's own test plays it beside the C16 from the same first instruction: the menu comes up in the same frame, level 1's first pass comes 195 frames after fire on both, and in play both run 134 passes in 522 frames.

Stop the Express

Every stored moving pose and every character shape, decoded in the game’s colours.

01 · Moving figures

Bodies made of character cells

The runner and the enemies are groups of character squares. A character code is a number that chooses one square’s shape. Some poses use a short drawing list. Each list says which character to draw, then how far to advance through the screen. Other poses store six character codes in a fixed rectangle.

Loading figures…

Every pose uses the selected train’s actual character shapes and colours. The pose controls show one stored variant at a time. They do not reproduce the game’s playback speed. The page’s reader for drawing lists is checked against $50A0 for every shown list and every character-code adjustment from 0 to 255. The caution sign also uses the $80 adjustment chosen by the game at $47C9. Addresses such as $50A0 name places in memory; the $ marks a base-16 number using digits 0–9 and A–F.

The same higher character codes can choose different shapes inside the train. A bird pose on the roof can therefore draw a different picture with the interior font. Pole and wire views run the original drawing routines at $4571 and $4709. The game’s routines choose which combinations appear during play. This browser also shows combinations that the game does not select.

02 · The character set

All 256 squares

Each character is eight bytes, one byte for each row of eight dots. A byte holds eight binary digits; each digit switches one dot on or off. A separate byte chooses its colour. The full train sets occupy $6DD7–$91E2. The shared interior patch begins at $91E3; four front patches begin at $9666.

The selectors above apply here too. All four designs and all three loading states match the font and colour memory produced by native $201E, twelve independent comparisons.

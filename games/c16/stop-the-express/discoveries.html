Stop the Express

Practice rules, a command recording that gets overwritten, and a round-counter failure reproduced with a forced test.

01 · Practice

Secret: C starts a forgiving practice game

Press C during attract play, the automatic demonstration, to start practice. Ordinary collisions flash the spare-life figures instead of killing the runner, and the timer stops decreasing. The practice game still updates its stored score. Practice hides the normal score display and leaves the high score alone.

Loading native collision example…

This example runs the original routines at $4999/$4A03 and $498A on the listed code. A routine is a small piece of the program with a particular job. Addresses with $ name places in memory, written in base 16 using digits 0–9 and A–F. C enters practice at $2155; Escape leaves it at $218B.

02 · The demonstration

Secret: ordinary play replaces the attract recording

The opening demonstration reads a list of commands beginning at $B02E. An ordinary game writes the player’s commands back into that same area. Practice skips that recording branch.

The list advances when the movement routine asks for a new command. A jump or fall already in progress can run without another poll, so this is a command recording rather than one stored key for every screen frame: $36D6, $36FD, and $3733.

Loading command recording…

A 64-command window from the authored 3,376-byte recording. The list stores zero, Space, and movement digits. Its later recording capacity extends to $CFFF.

03 · A forced boundary test

Bug: round zero makes enemy setup overwrite code

The round number occupies one byte, which holds a value from 0 to 255. Increasing 255 wraps the number to zero. The next roof setup uses the round as an enemy count. The setup loop subtracts one after each enemy record. Starting at zero makes that subtraction wrap to 255, so the loop runs 256 times before stopping.

In a forced round-zero test, enemy records ran from $1D00 through $24FF, and the value marking the end of the list landed at $2500. Those writes damaged game code, including the entry at $1E00. The test proves that the setup writes over code; a played route through 255 rounds has not been established.

The listed entry begins 4C 06 1E 4C AA 1E AD 19.

This button sets round zero and runs the original routine at $51F5 on a private copy of the listed memory. The game’s round increment is at $2AA0. The emulator reproduced the same overwritten entry bytes.

04 · Background movement

A forty-cell strip wraps a shorter pattern

The ground has forty stored cells, but its pattern repeats every six characters. The two-cell shift saves cells 34 and 35, then copies them to the front. The last four physical cells are a continuation of that repeating pattern.

The copied pair is $18E2/$18E3; the physical row ends at $18E7. The stepper matches the shift at $4960, including arbitrary input rows.

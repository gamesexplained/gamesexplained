Stop the Express

The two stages, all four carriage designs, and the tables that change the journey.

01 · The carriage pictures

Every train, inside and out

A layout stores one character code, a number that chooses a shape, for each square. The code chooses an 8 × 8 shape and its colour. Each train has a roof layout, an interior layout, and a final engine picture. The converter’s train gallery identifies the designs as the original ITA train, Deutsche Bahn, MÁV Class V43, and Il Settebello.

Loading layouts…

Addresses such as $258B name places in memory. The $ marks a base-16 number, written with digits 0–9 and A–F. The roof and interior have thirteen rows; the engine picture has fourteen. These are the complete stored pictures before the game adds moving figures, carriage numbers, and scrolling. The tables of addresses that select these layouts are at $258B–$25A6; engine drawing starts at $2AA8.

02 · Difficulty

Longer trains, then less time

Later rounds add carriages until the train has ten. Time first rises to 200, then falls to a lasting limit of 150. The round counter keeps increasing after the last time-table entry. The counter fits in one byte, which can hold numbers from 0 to 255. At rounds 252–255, adding four goes past 255 and wraps back through zero, so the carriage count drops to 0–3. A played route to those rounds has not been established.

Design table $2573, carriage limit $268B, and time table $5339. The widget uses those stored bytes; its results are checked against the original setup code across rounds 1–255.

03 · The two stages

The brake is only half the finish

The roof exit leads into the carriages. Near the front of stage two, the approach routine carries the runner into the engine room and places him at column 37, row 17. The program then sets an engine-room flag, a stored yes/no value, that allows free horizontal movement: $5344.

The brake accepts columns 18–20 with the runner above row 15. After the brake is set, reaching column 2 starts the finish. The remaining time is then added to the score at ten points per time unit: $4D36, $3497, and $2AA0.

The screenshots use the original interior and approach routines. The round and progress values were set for inspection. They do not document a completed playthrough.

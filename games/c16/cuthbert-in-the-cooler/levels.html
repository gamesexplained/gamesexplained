1985 · Microdeal · Commodore 16 / Plus4

Cuthbert in the Cooler

Ten layouts repeat as the level number advances. Its decimal digits choose the maze and guard count.

01 · All level numbers

The units digit chooses the maze

The level number is stored in one byte, a number from 0 to 255. Its units digit, the rightmost digit, chooses one of ten layouts.

The maze is drawn from the original data. Numbered dots mark the centre of each guard's two-by-two character block at its starting position. Grey dots are inactive at this level. Characters, colours, object counts, and active guard starting positions are checked against the original level-building code for all 256 values.

Levels 1–9 use the first nine records. A units digit of zero selects the tenth. The level byte at memory address $002E advances from 255 to 0, then 1. An address names a position in memory. A leading $ marks a hexadecimal number, written with digits 0–9 and A–F.

02 · Difficulty

The guard count follows the tens digit

A tens digit of zero activates four guards. One activates five. Higher tens digits activate six. The hundreds digit is ignored by that table, so level 100 returns to four guards.

The guard-count limits are at $1B8C. Guard shapes cycle every four levels; colours cycle every eight. Each layout stores seven starting positions, although the normal activation table uses at most six.

03 · The ten records

The layouts favour different pickups

Keys have a face value of 100, rings 200, and apples 300. These totals add the face values. The score adder can lose points when it carries into the next digit.

Maze packets occupy $2011 through $2100. The table at $1BA7 uses the units digit to find each layout's guard starting positions.

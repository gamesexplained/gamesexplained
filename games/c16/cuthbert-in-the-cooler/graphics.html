1985 · Microdeal · Commodore 16 / Plus4

Cuthbert in the Cooler

Cuthbert, guards, bombs, and pickups are drawn with characters. Their source frames are preserved here.

01 · The original shapes

The cast, frame by frame

Original picture data and game colours. Cuthbert's previews remove the stored position offsets so he walks in place. Walking and idle-bomb previews use the measured first-maze pace of roughly eighteen updates per second. The first three fire frames each last three game updates. The fourth lasts one update before the explosion is erased. Actual walking frames advance only on accepted movement. Guards share a counter that switches between two groups of pictures, called banks, after twenty-one active-enemy updates; the preview uses the first maze's four guards.

A directory at memory address $3300 lists where the game keeps its horizontal and vertical player pictures, fire pictures, and two guard banks. An address names a position in memory. A leading $ marks a hexadecimal number, written with digits 0–9 and A–F. Horizontal player images use four characters; vertical images have room for six. Two colours are shared across the screen; each character also has its own colour. Together they recreate Cuthbert's suit.

02 · The moving font

Each guard gets six character slots

The C16's display chip draws characters rather than hardware sprites. The game gives a guard six private character slots and replaces their pictures as the guard moves.

The drawing code at $1CA6 copies a source image into a temporary work area. For a half-step, the code shifts the picture by four pixels horizontally or four rows of pixels vertically. It then writes the result back into the font. Normal guard slots start at $3E70 and are forty-eight bytes apart. A byte stores a number from 0 to 255. Cuthbert uses the last six slots, at $3FD0.

The seventh allocated guard is inactive in normal play. An overflow in the address calculation gives the wrong location for its character pictures: $3E91 instead of $3F90. The table that chooses how many guards to activate stops before that slot.

03 · Retained source images

Each guard bank retains a fifth image

The normal shape table selects images one through four. Each source bank also contains a fifth thirty-two-byte image. The two retained images are shown below in one inspection colour.

The tail is grouped into eight-byte pieces for inspection. Its intended arrangement and purpose remain unknown. The retained images do not establish that an extra enemy can appear in play.

04 · The static character pieces

The alphabet shares space with the maze

Single-colour inspection of glyphs, the pictures inside character slots, numbered $00–$68. Letters and digits occupy the early slots. Pickup, wall, bonus-bar, and bomb pieces follow. Fire and moving-actor slots are generated during play.

The text-printing code at $127E converts ordinary letters into their screen-character numbers. Small control values also choose graphical pieces: parameter $18 becomes glyph $58, the bonus-bar segment.

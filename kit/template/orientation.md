# {{title}} — orientation

How to get from the contributor's own copy to the analysed state. Someone
else must be able to follow this exactly.

## The image

Which file, which release (original, re-release, crack with trainer),
what the directory shows. Note anything that is not the original game.

## From power-on to play

1. Attach the image and start it, as the platform's `steps` skill
   (`media`) and its tool skill say.
2. Loader / trainer / menu: what appears, what was chosen.
3. Key or button that starts play, and how long to wait.
4. Snapshot taken: `work/<state>` in the platform's snapshot format
   (`steps`, `snapshot`), at what point.

## The parts

Only for a game of several parts (`kit/skills/core/15-parts`): each part
in the order it is played, the files it loads, and the route to its
snapshot from power-on or from the part before. Delete this section for a
game that is one load.

## Steady state

Interrupt vectors observed during play, the banking configuration, where
the game's code and data sit, whether anything is reloaded per level.

## The loader, in a paragraph

What it appears to do. Not annotated further, by policy.

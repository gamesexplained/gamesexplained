# Workarounds for MAME on the Game & Watch

MAME is the second machine, not the one the kit's checks drive, so it
has no check of `kit/gnw/check_emulator.py` to fail. Its agreement with
the kit's machine is `kit/gnw/check_machine.js`: 64 programs of 64 agreed
instruction for instruction on 8 November 2026. A build that disagrees
adds its section here, with the program and the line where they part.

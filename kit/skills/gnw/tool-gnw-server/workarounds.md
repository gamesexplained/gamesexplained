# Workarounds for the kit's Game & Watch server

One section per check of `kit/gnw/check_emulator.py` that fails on some
build, with what to do instead. The server is the kit's own and passed
all nine checks on macOS on 8 November 2026 (`kit/gnw/INSTALL.md`), so
there is none yet. A run that finds one adds its section here.

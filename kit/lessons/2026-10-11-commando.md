## 0.0.148 · 2026-10-11 · Commando (C64) · air

- **Diff a crack against the original release before calling its changes
  unknown.** Commando's crack credits itself with a bug fix, and its start
  has eight NOPs; both stayed open questions while the run had only the
  crack. Elite's own disk, stopped at the same hand-over and compared byte
  for byte, differed in 29 of the game's 19,450 bytes: the fix (the
  high-score walk started one entry too high) and the NOPs, which had
  replaced a copy of a CBM80 signature to `$8000`. Where the original is
  not on the image, ask the contributor for it.
- **A restart that lands where it should has not yet been shown to work.**
  The 1985 release's reset stopped cleanly at the game's start, and the
  first reading was that a reset restarts the game. Played on, it never
  did: the KERNAL jumps to a cartridge before it sets up the chips, so the
  game's own copy into the RAM under I/O turned the display off, and the
  title's test for fire waited for a value the uninitialised CIA port
  cannot give. A run "into area 3" turned out to be the attract mode
  cycling its views. Pressing fire, and reading `$D011` and `$DC02`,
  settled it.

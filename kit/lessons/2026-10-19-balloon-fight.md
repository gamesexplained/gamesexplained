## next · 2026-10-19 · Balloon Fight (NES) · Zihe Jia (icyriver2023) with Claude Fable 5.1

- **Name a request bit by the routine that takes it, never by the routine that sets it.** Balloon Fight's game code sets bits in four sound-request bytes, and the driver reads them in its own order: a flap set as bit 4 was answered by the routine two bits along, a bit set for the thunder was never read at all, and five of fourteen effects were named after the wrong routine until each bit was poked into a paused game and the driver's writes recorded. When a routine leaves a number for another to act on, read the taker's dispatch (its shifts and branches) before writing what each value means, and where the emulator can record the taker's output, record it for every value.
- **A split pointer table with a label on its second half is not `lo_hi_address`.** regenerator2000 0.9.20 pairs each labelled stretch with its own halves, so a table whose high bytes carry an automatic label mints addresses from the wrong pairs, in the middle of routines; the coverage queue showed them as bare runs inside described code. Type such a table `byte` and say in its comment how the halves pair.
- **Verify a port against the game's input timing, not only its arithmetic.** The flight port matched gravity, the flap and the limits to the byte and still failed the lockstep: the game reads the pad every third frame and refuses a flap for nine frames after one. Run the game's own routines for the whole loop the mechanic lives in, with the counters that gate it, and compare every frame.
- **A machine whose picture lives in the video chip's own memory has no picture in the listing.** On the NES the tiles, the nametables and the palette are the PPU's, outside the CPU's 64 KB, so a page cannot draw from the listing as a C64 page does; it carries the pieces it draws as data (`kit/nes/snapshot.py`'s `ppu` and `oam`). The cheapest oracle for a level renderer is the emulator's own nametable, captured for every layout by stepping the level index and clearing the level, and compared cell by cell below the status bar; the first game's renderer was wrong in a propeller's attribute quadrant and a bonus round's sprite palette until that comparison said so.

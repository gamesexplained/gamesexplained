## 0.0.228 · 2026-10-24 · Flowers of Crystal (BBC Micro) · air with Claude

- **Read every line built the same way before calling one special.** A
  finding drawn from one line's shape is a claim about the lines that
  share it. The Discoveries draft said a vanished sky spitter's "You are
  safe." came through another `IF`'s `ELSE`, while the storm and the
  cave said it on purpose. The storm's line 4010 and the cave's 4048 are
  built the same way as the spitter's 4052, and the live run had shown
  all three printing it; the copy pass caught the claim on reading the
  two lines.
- **A table read by an index is not a list of outcomes.** The Maps tab
  first showed part 2's three next-place DATA lists, one value for each
  of the ten places, as where each spell leads. Reading every line that
  restores those lists, and the line after each call, showed spells are
  offered at seven places only, two of the lists are read at four places
  each, and the Globs, the flight, the left path and the castle set the
  next place again themselves, so most of the table's entries are never
  read or never matter. Before a page shows a table entry as what
  happens, find the code that reads that entry, and what runs after it.

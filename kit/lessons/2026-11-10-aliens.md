## 0.0.322 · 2026-11-10 · Aliens (C64) · unorig with Claude

- **Read the manual's promises against the code, line by line.** The
  manual says a level can be skipped with a key and RESTORE, and that a
  game with a skipped level never shows the final screen. Checking that
  sentence against the code corrected a verified fact that had the skip
  backwards: the game's own skip sets the flag that withholds the ending,
  and the cracked disk's skip key clears it. The same check found a
  handler the listing called unused, reached by storing one byte of its
  address (`LDX #$56`, then `STX $FFFA`) into the NMI vector, which no
  references search shows.
- **A stage file's header of words is not a split table.** Every stage
  of this game starts with 20 little-endian words, entry points then
  table addresses. Typed as a table of low bytes followed by high bytes,
  every part's listing read them wrong without any check failing, until
  the export lost bytes in one part. Type a header by how the code reads
  it (`JMP ($8000)` reads a word), not by how the bytes look.

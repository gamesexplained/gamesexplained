## 0.0.354 · 2026-11-17 · Ghostbusters II (C64) · air with Claude

- **A crack's patch to the game's code can hide a bug that only the
  original has.** The Ghostbusters II run analysed two cracked releases.
  Reading the original disk (the C64
  Preservation Project's G64 of both sides) for its story text showed
  one change to the episodes' code: at eight museum addresses the
  original loads the walker's room to start a check that stops a
  Ghostbuster walking into his partner, and the cracks jump over all
  eight checks. Played on the original, the check traps both
  Ghostbusters for good when a doorway sets one down on the other, which
  joystick input alone reaches from the start of the museum (17 November
  2026). The cracked copies cannot show it, so a run that compares
  releases now treats a patch in the game's own code as a lead and
  plays the original there (`10-orient`, step 1).

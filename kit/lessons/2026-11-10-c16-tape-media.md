## 0.0.321 · 2026-11-10 · Tycoon Tex (C16) · air with Claude

- **A turbo loader's format can be read off the loader, and the game's
  listing says whether it was read right.** The C16 had no reader for a
  tape, so its three games had no `media.json` and each run had mapped
  its tape from checkpoints during the load. `kit/c16/media.py` now reads
  a TAP as pulses: the KERNAL's files, then Novaload's. Novaload's layout
  came from the 171 bytes of loader in the first file's header,
  disassembled: a wave timed against timer 2 loaded with `$018F`, bits
  lowest first, a leader, `$AA`, a name, six bytes and blocks of 256
  with a running checksum. Tycoon Tex's file `NOVA` then decoded to
  12,288 bytes with all 49 checksums right, equal to the game's listing
  at `$1000`-`$3FFF` byte for byte. Mr Puniverse's tape gave two
  Novaload files and Prospector Pete's one, every checksum right.
- **List what a header carries after the name.** The KERNAL fills a
  header's last 171 bytes with spaces; Novaload keeps its loader there.
  A reader that listed only named files and their bytes would have put
  the loader in no item. The reader makes a header that holds anything
  else an item of its own.
- **A file that loads over the stack starts itself.** Tycoon Tex's first
  file loads at `$0140`-`$023F`, and its bytes from `$01C3` to `$01FF`
  are all `$02`, so the KERNAL's next return goes to `$0203`. The run
  had left "how control first reaches the stub" open; the file's own
  bytes answered it, and a checkpoint on `$0203` confirmed it.
- **The ledger is for the game's data, and a loader gets one line.**
  air's steer on reading this work: the site wants every piece of game
  data that is interesting uncovered, and cares little for how a loader
  or an unpacker works, least of all on a page. The stack trick above
  cost a live trace and belongs in `orientation.md` only. `12-media` now
  says where the time goes, and `70-minisite`, "Discoveries", that a
  loader's workings get no section.
- **Test the tone test on a tape with more than one tone.** What is
  left over after decoding must be told from bytes in an unknown format.
  "Nearly all waves one length" passed the three real tapes and failed
  the made-up one, where a Novaload trailer runs into a KERNAL leader.
  The reader now counts how often a wave differs from the one before it.

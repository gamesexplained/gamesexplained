## 0.0.44 · 30 September 2026 · Ghostbusters · unorig with Claude

**A test must contain cases that have to succeed.** Ghostbusters' account
number is checked by the game against the player's name. The port of the
checker read the number's four bytes in reverse order and still agreed
with the game on 20,000 random names and numbers, because nearly every
random pair is refused by both. Numbers the game itself printed, fed back
in, failed at once. `60-verify` now says to put the game's own codes in
every such test and require that they pass.

**Pace a port by what the machine measured, per state.** The Play tab's
port ran at the original's pace only once each pass cost the median
cycles the game took in the same game state, measured by hooking the
simulator where a pass begins and ends. Within about 1 % on the walk, the
shop, the drive, GHQ and Zuul, where a cost worked out from the lockstep's
own counts had left the game stuck in one state. `70-minisite` gives it beside the fit.

**The raster interrupt is latched.** The page's runtime waited a frame
for an interrupt the game's start-up had enabled after its line had
passed; the VIC raises it at once, from the latch in `$D019`. The C64
reference now says so.

## 0.0.112 · 4 October 2026 · Jumpman · JankFoundry with Codex

**Plain-language copy can change a verified fact.** Gunfighter's fixed
respawn point became "starting position" even though one enemy starts
elsewhere. Comparing initialization with reset caught that change in meaning.
The puzzle respawn wording also needed the last-life branch checked. Jumpman's
timer counts serviced game updates; some interrupt entries return before that
work. The article, feature list and level notes need the same measured unit,
and private-code links need the part that owns the routine. Correct technical
evidence does not validate every paraphrase of it.

**A finite item count is an assumption to verify.** Fastest-speed backlog
testing needed the original placement and deferred occupancy rules. The
collector alone did not enforce the proposed pickup cap: deferred drawing
can leave old occupancy visible, and collection can run before foreground
completion work. A supplied zero-count case tests an underflow guard, not
whether play can reach underflow. Execute the original divider over several
periods, including its fastest setting, before deriving a queue bound: reset
and increment in one service change its period. State the initial queue,
producer/consumer order and pickup assumptions; a permissive model overflowing
does not establish a reachable game failure. Jumpman's bound stays conditional
where those assumptions are unresolved.

**RAM and its displayed value need separate stops.** Dragon Slayer's hit
award and stair drawing do not happen at the same instruction. Record the
score at its award stop, then let the original foreground drawing finish
before taking the matching screenshot. Completion can itself change the life
or movement state, so one later capture cannot stand for both phases.

**A suspicious byte needs its surrounding state.** Controlled collision
setups found a terrain-flag difference while ordinary input routes still
climbed successfully. The tests supplied pose masks and a foot probe at
current Y+11; those choices must be stated because ordinary movement can
retain a probe from an earlier position. Coordinates alone do not define
the collision state. Run ordinary inputs before promoting a table anomaly
to a claim about a blocked route or fall.

**Coverage can hide a misplaced entry or a misread record.** Checking every
stored level callback found two more names on preceding instructions after
the sample exposed PLF09's misplaced tick label. Check every entry in that
header format against instruction boundaries; a named preceding return can
hide behind 100% annotation coverage. Follow later pointer writes too:
Grand Puzzle III installs different callbacks and a bomb table during its
transformation. Execute both the request and the resident installation step
before checking those replacement entries.

**An eraser can look like a no-op on an empty bitmap.** Parsing Jumpman's
shape records separated row lengths and offsets from pixel values: an alleged
collectible stamp was an eraser. Execute the original drawing routine on
filled as well as empty backgrounds before assigning a material. In the
native stair comparison, count changed pixels separately from all the writes
the shape makes.

**A nonzero input can enter a zero-state trap.** Exhausting the chooser's
16-bit input space found three nonzero seeds missed by a passing sample.
The original routine retries forever; the page threw an uncaught error.
The check must cover termination as well as returned values. Detect repeated
state in the original retry loop rather than treating a step limit as a
successful return, and exercise the published control with those failing
inputs. The loaded-seed sequence remains a separate reachability question.
The existing exhaustive-input advice in `70-minisite` already covers the
decision to enumerate this small input space.

**Comments have an image state too.** Moving the listing from gameplay to
the original loaded image left comments describing changed operands. The
comments must be rechecked against the new bytes. Comparing each captured
image with its disk input distinguishes actual loader self-modification from
an unexplained mismatch. Byte identity and annotation coverage remain separate
from the correctness of a comment's interpretation.

**A requested frame count is not elapsed time.** A rejected oversized frame
advance leaves the machine unchanged. The VICE notes now require supported
batches and a matching completed-frame count; the Python helper raises on
errors or incomplete advances so replay scripts cannot silently skip time.

**Count loaded programs, not just occupied addresses.** Jumpman's resident
image loads thirty-two different 2 KB level programs into the same place.
One play snapshot would miss thirty-one of them. The parts workflow in
`10-orient` supplies the inventory and separate ledgers. Jumpman's original
loader captures each file before initialization, and its notes identify controlled selections separately
from campaign progression. Retained tails are compared against their donors
and active readers rather than mistaken for executed code. Resolve header
callbacks and per-item pointers before excluding a suspected alignment gap.

**The collector's target count may not bound its records.** Some levels
have special records beyond their ordinary target count; one has no
terminator before the following code. Follow the scanner's actual stop
condition instead of cutting the table at the completion target or inventing
a sentinel. PLF13's scanner has an eight-bit index that wraps within a small
window; it does not advance through all memory. Enumerate that window for
incidental terminators and false matches. Original-sampler tests over the
actual geometry, position and pose masks found no unmatched ordinary contact;
ordinary erasures preserve that result. The missing sentinel is established,
but these tests supply no legal failure route or proof about every interrupt
interleaving.

**A readback model needs its own evidence.** The sound driver reads a
writable SID register. Live CPU probes returned the last global SID write,
not a per-voice shadow. A test double returning that register's own stored
value would make two wrong models agree. Use the emulator's CPU instruction
to read after changing a different register, and vary the delay when testing
decay. Jumpman's player names its omitted bus decay and within-frame timing;
ordered register agreement does not establish waveform identity to physical
hardware. The shared verification proposal is recorded in #194.

**A callback's neighbours change its result.** Freeze reaches zero before
clearing its input override; platform support reads the old direction on a
corner; follower sample age depends on replay and recording order.
Run the original dispatcher, or first establish its order before scheduling
callbacks in a harness. Freeze needs the last nonzero countdown, zero-entry
call and next input poll tested separately. Jumping Blocks needs the corner
where support uses the saved direction before movement changes it.
Follow the Leader needs creation on both sides of its cursor boundary and
after wrapping: replay increments the read cursor before reading, then
recording writes the next sample, so sample age differs from cursor gap.
Name private callback clocks separately from shared player/hazard pulses.
Ordinary-input captures establish only the controlled cases actually reached.

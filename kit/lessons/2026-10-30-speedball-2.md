  recorded start would have typed the title's bytes as code at the
  routines' boundaries, and `check_listing.py` would have passed it,
  because every recorded byte would then be Code. It showed only
  because the run had already compared the menu, gym and match
  snapshots and found different code at $C000 in each. The run
  kept from the code map, inside the buffer, only the starts a trace of
  the snapshot reaches from its entry, and listed each buffered routine

  game's own unpacker. Where a game runs code in a buffer it fills during
  play, trust the code map there only as far as the snapshot's own

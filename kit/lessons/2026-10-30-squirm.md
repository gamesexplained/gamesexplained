## next · 2026-10-30 · Squirm (C64) · air with Claude

- **A file saved from the machine it was written on carries what that
  machine's memory held.** The game's one file is a BASIC stub, `10 SYS
  15133`, and the game; between them sit most of the BASIC program of
  the assembler it was written with and that program's arrays, 2.5 KB
  that the save picked up because they were in memory. The stub's link
  points straight to the end of the program, so a BASIC lister shows one
  line and the rest reads as data. Following BASIC's own line links from
  the first place they make a chain (two bytes pointing a little further
  on, two bytes of line number, then keywords as tokens) read the
  program back from line 15 to line 340, with its name, its authors and
  its version date. When bytes between a stub and the game hold BASIC
  tokens, read them along their links before calling them data: they
  name the tools the game was made with and show which bytes are not the
  game's.

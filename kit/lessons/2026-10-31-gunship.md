## 0.0.279 · 2026-10-31 · Gunship (C64) · air with Claude

- **A checker briefed with a wrong fact passes the comments that repeat
  it.** The sample's brief carried the run's `facts.md`, which gave the
  high byte of a unit's position as a map square where it is a sixteenth
  of one. The checker marked "the Hind's x square" right, and the same
  unit was in six more comments. The page's map widget, which ran the
  game's own map routine, showed the fact wrong. Before briefing a
  checker, read the conventions its brief will carry against the code once
  more, and when a fact in the brief turns out wrong after the sample,
  count the sampled comments that repeat it as wrong and correct them with
  the others.
- **"Every" checked on one is a claim about one.** The listing said every
  BASIC program in the game starts with the same line that stops LIST.
  Five of the six do; the debriefing does not, and one of the five has it
  on line 1, not line 0. The claim came from one program tested live and
  had reached two comments, `features.md` and a Discoveries heading. When
  a comment or a page says "every", "all" or "each", list the members and
  check each one.
- **A font can draw letters as digits.** The flight's map font has no J,
  X or zero: codes 10 and 24 draw 7 and 8, and the O stands for 0. Decoded
  by alphabet order, the target "T-72" read "T-J2" and "SA-8" read "SA-X",
  and code `$2E`, read as a full stop, is an exclamation mark. Render
  every glyph a string uses before trusting a substitution table built
  from order, the letters as well as the punctuation.

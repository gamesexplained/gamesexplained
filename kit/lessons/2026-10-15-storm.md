## 0.0.166 · 2026-10-15 · Storm (C64) · air with Claude

- **A variable the new game leaves alone is an input to every test of
  it.** Storm's start-up puts back the rooms, the energies and the armour
  but not the counters of keys, brooches and scrolls, and the run wrote
  that down as a discovery and went on. Only after the pages were built
  did it read the laboratory door's test against the carried counter:
  the door opens on exactly three brooches, three can be taken in a game,
  so a game that starts with one from the game before and takes all
  three can never reach the ending until the game is loaded again
  (checked live). Wizball's shield timer outlives a quit the same way.
  When the start-up does not set a variable that play changes, read each
  test of it with the values an earlier game can leave there, not only
  the ones a fresh game reaches.

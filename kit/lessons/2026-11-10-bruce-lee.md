- **Decode every key code from the matrix before naming the key.** The
  Bronze listing called the four keys read in play "the function keys",
  with RUN/STOP restarting the game. The table they come from holds four
  row and column pairs, and against the keyboard matrix they are F1, S,
  SPACE and V. Nobody had checked a code against the grid, because each
  name read as plausible. `kit/skills/c64/c64-reference`, "Keyboard and
  joystick", now says to name keys from their pairs.
- **A first sample on a listing written by two models found 16 of 60
  comments wrong.** The errors were of the kinds a reread finds: a role
  described too narrowly, a comparison read the wrong way round (a
  minimum distance taken for a maximum), and a record that starts two
  bytes before its label. All were corrected, and the audit is
  recommended in the game's `TODO.md`. Drawing the frames for the
  Graphics tab found one more the sample missed: a second copy loop
  described as a mirrored copy, when the game has separate frames for
  each direction and the loop copies frames two bytes wide. A widget
  drawn from the bytes checks the comments it reads.

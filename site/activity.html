Site activity

What landed, day by day

Games Explained changes every day. New games arrive, pages get better, bugs get fixed, and the kit that explains the games keeps improving. This page counts what reached the site each day, read from the repository whenever the site is built.

Day by day

Every change that landed and every issue fixed, newest first. A change is tagged with what it touched: a game, the kit, or the site itself.

How it is counted

A change
A commit on the repository's main line: a pull request when it is merged, or a commit an admin pushed straight to main. The kit's automatic version number commits are left out. A change is dated when it landed.
New games
Changes that add a game to the site. Total games is how many the site carries at the end of each day.
Pull requests merged
Changes that came from a pull request.
Issues fixed
Issues closed as completed, on the day they were closed. Issues closed as not planned are left out.
Kit improvements
Changes to the kit: its scripts, skills, platform notes and lessons, and the rules agents follow (AGENTS.md). Many games bring one, since every run ends by fixing what slowed it down.
Days
Days run midnight to midnight in your own time zone, and the last one ends when the site was built.
